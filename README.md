# 《云海猎团 Cloudsea Hunting Corps》· QQ 群异步回合制 RPG·PvE 设计稿

> 这是一份**原创 IP** 的完整设计稿。玩家是**巡游者**——无角色抽卡，可换的是**武器 / 装备 / 符文**。
> 在 QQ 群里用短指令打回合制战斗：**战前配好、战内只发 `1`/`2`/`3`**，单次决策 ≤30 秒，超时自动托管，一局可跨天。

**三条来源的融合**：① QQ 群异步回合制骨架（碎片性 + 轻量性为第一性约束）② 讨伐型战斗循环（部位硬度 / 部件破坏 / 阶段窗口 / 武器流派 / 战术资源博弈）③ 长线资源与装备循环（武器强化 / 符文加工 / 防具套装 / 定向保底 / 超限突破）。

## 四、核心设计速览

| 主题 | 一句话 |
|---|---|
| **职业与武器解耦** | 职业决定「**攒什么、放什么**」（专属资源 / 战技 / 绝技），武器决定「**怎么打**」（模式 / 节奏 / 资源注入效率 G×T）。14×14 = 196 组合，非偏好武器**零数值惩罚** |
