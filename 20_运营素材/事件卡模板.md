# 20 · 群内活动模板与事件卡（周常 6 ＋ 赛季 6 · 共 12 张）

> **定位**：QQ 群运营活动模板与赛季事件卡（三期批次 58 产出，2026-09-07）。每张卡五栏（目标／玩法／挂钩／奖励／限制），主持按卡开团，数值不临场发明。
> **数值纪律**：奖励与门槛数值一律引用 `$C.ECON.*`（`12_全局常量表.md` §G，值口锚 `18_装备与素材图鉴/06_素材掉落总表.md` §五–§七）；卡面不写裸数。
> **金币账红线**：活动奖励走**公会勋「群内补给」渠道**（勋来源既有四口之一，`06` 号 §M6.3 契约）与**「非日常大额支出／活动限时货架」口径**（`06` §三）——勋不可兑金币、不可交易，故**不改写 `$C.ECON.GOLD_DAILY_INCOME 42000`／`GOLD_DAILY_COST 46000` 日均账**；金币只经既有计量条三档照发（其期望 4,000/日已入账，`06` §六演算），活动卡一律**不额外加发金币**。
> **联动系统**：蚀潮计量条 30/60/100% 三档（`06` §六）｜公会勋货架（`06` §五）｜蚀潮巨兽窗三窗 12:00／18:00／21:30 各 120 分钟（`06` §七）。

## 一、周常活动模板（6 张）

### 周1 · 三窗巡值

| 项 | 内容 |
|:---|:---|
| 目标 | 单周内蚀潮巨兽三窗（12:00／18:00／21:30）各参战 ≥1 场 |
| 玩法 | 群内接龙报名，各窗开窗时点名集结；战报行计场次，跨天个人实例照 §七 口径保留 |
| 挂钩 | 蚀潮巨兽窗（`06` §七） |
| 奖励 | 公会勋 `$C.ECON.METER_TIER2_GUILD`；掉落照 §七 既有口径照发不另加（每场保底晶核＋残片，上级符文率 `$C.ECON.BEAST_ADV_RUNE_RATE`） |
| 限制 | 每周每人一次；奖励勋走「群内补给」口，金币不加发 |

### 周2 · 计量冲档

| 项 | 内容 |
|:---|:---|
| 目标 | 当周在任一窗把全服计量条推过 60% 档者记名，推过 100% 档者加记 |
| 玩法 | 达档即记，全服人人发奖口径不变（`06` §六「不抢最后一刀」照旧）；本卡只追加勋，不动档内金币素材本额 |
| 挂钩 | 蚀潮计量条三档（`06` §六） |
| 奖励 | 过 60% 档加发勋 `$C.ECON.METER_TIER2_GUILD`；过 100% 档加发勋 `$C.ECON.METER_TIER3_GUILD`（档内 `$C.ECON.METER_TIER1/2/3_GOLD` 金币与素材照 §六 本额，不重复加发） |
| 限制 | 加发部分每周一次；不与周1 勋叠加计次 |

### 周3 · 货架开箱日

| 项 | 内容 |
|:---|:---|
| 目标 | 当周在公会勋货架完成任意兑换 1 次 |
| 玩法 | 兑换截图报备；货架价格与限量照 `06` §五 原样，活动只附权益不改价 |
| 挂钩 | 公会勋货架（`06` §五） |
| 奖励 | 「精炼矿石改选回炉券」×1（权益卡，本卡申报、勋价 0；矿石本身仍按 `$C.ECON.GUILD_ORE_PRICE` 勋/枚照价）；上级符文 `$C.ECON.GUILD_ADV_RUNE_PRICE`／残片 `$C.ECON.GUILD_SHARD_PRICE` 照常限量 |
| 限制 | 券当周有效、不可交易；残片周限 3 片不放宽 |

### 周4 · 引航新人

| 项 | 内容 |
|:---|:---|
| 目标 | 老带新：新人进群完成首战并走完入群流程 |
| 玩法 | 师徒组队报名，新人首战战报行标注「引航」；流程时效沿用 `12` 号 §H 入群与决策秒数既有约束 |
| 挂钩 | 公会勋来源·引航新人（`06` 号 §M6.3 契约） |
| 奖励 | 师徒各勋 `$C.ECON.METER_TIER2_GUILD` |
| 限制 | 每人每周至多记徒 1 名；奖励勋不可兑金币 |

### 周5 · 稀有掉落周记

| 项 | 内容 |
|:---|:---|
| 目标 | 晒出本周 1 条稀有档以上掉落（RARE 0.08／RELIC 0.02 带内）并注明出处 |
| 玩法 | 群内跟帖晒落，主持按 `18_/06` 分册掉率带核真伪，收录进周记 |
| 挂钩 | 素材四档掉率带 `$C.ECON.DROP_T_RARE`／`$C.ECON.DROP_T_RELIC` |

| 限制 | 每周每人 1 条；伪造掉落记录取消当周资格 |

### 周6 · 残片周历

| 项 | 内容 |
|:---|:---|
| 目标 | 当周集齐遗械残片 ×3（货架周限或巨兽窗保底渠道均可） |
| 玩法 | 残片到账报备累计，集满 3 片销历 |
| 挂钩 | 货架残片 `$C.ECON.GUILD_SHARD_PRICE` 勋/片（周限 3）＋巨兽窗每场保底残片 ×1（`06` §七） |
| 奖励 | 销历者勋 `$C.ECON.METER_TIER3_GUILD` |
| 限制 | 每周 1 历；残片渠道与限量照 `06` §五/§七 原样，不放宽周限 |

## 三、主持须知

1. **开团前**：核对当周已开卡数（周常 6 张互斥计次，赛季卡按季结算），勋发放统一走「群内补给」口登记。
2. **发奖时**：勋数值只认卡面 `$C.ECON.*` 键值（`12` 号 §G 现值），不临场加码；金币与经验永不在活动侧加发。
3. **红线**：任何卡不得改写 `$C.ECON.GOLD_DAILY_INCOME`／`GOLD_DAILY_COST`、不得动货架价格与限量键、不得把勋兑换成金币或转移。
