## 一、N1 · 兰恩（巡游同伴 · 观察员）

> 弧线锚：从"只会记录的新人"到"接过前代意志的人"（G1）。**互文锚**：观测量表祖本与续页／扉页署名「观察员」／灰岗印盒／「先看后打」门径（N01_兰恩.md 剧情大纲收束段）。

| 场景 | 台词 |
|:---|:---|
| 初见 | 「潮痕刚变了两回，你察觉到了吗？……没有？那就对了，所以要先看后打。」「兰恩，观察员——名字是刚署在扉页上的，册子还在手里热着。」 |
| 委托 | 「这单先别急着拔锚。上一队记的兽踪页给你，看完再走，省的是命。」「打完回来把落点说一声，我补页。」 |
| 闲聊 | 「老港主把印盒交给我那天说，册子交给会记的人。我现在天天怕漏记一笔。」「你上回说石獭换壳前会拍水？我记下了，署你的名。」 |
| 离线留言 | 「你不在，我把今天的潮痕对了三遍，没大事。」「印盒我擦好了，回来验。」 |

## 二、N2 · 铎恩（浮港铁匠）

> 弧线锚：从"打铁的"到"读懂遗械残片的人"。**互文锚**：门楣钉残片（不交不回炉）／「先认纹，再开炉」新规矩／G2 铸钟锻件单（N02_铎恩.md 发展—收束段）。

| 场景 | 台词 |
|:---|:---|
| 初见 | 「站远点，火星不认人。」「……新来的？想打交道先认纹，我这儿的规矩。」 |
| 委托 | 「料我挑过了，纹都对上了才开的炉。」「断了拿回来——断口我也要看。」 |
| 闲聊 | 「门楣那块旧片？不打，也不回炉，就钉在那儿。」「打了半辈子铁，如今先认纹再开炉，多一道工序，少十回糊涂。」 |
| 离线留言 | 「钟台的件赶出来了，火候照钟谱来的，差不了。」「你那把刀我顺手养了养，别谢，断口我还没看够。」 |

## 三、N3 · 卡戎（前代巡游者 · 老锚）

> 弧线锚：凿锚脉的人：动机在怒涛揭晓，不是恶人。**互文锚**：「齐口、收刃、回带」三道手法／「到怒涛水段再讲」的留白／停锤后雷雨夜锤音只在旧脉／断锚屑移交（N03_卡戎（新）.md 发展—收束段）。

| 场景 | 台词 |
|:---|:---|
| 初见 | 「会认凿痕吗？不会就跟着看。」「齐口、收刃、回带，记下这三道，别的以后讲。」 |
| 委托 | 「巡锚的活，走旧脉、不进深。」「我停你就停，我摸哪儿你记哪儿。」 |
| 闲聊 | 「锤音只在雷雨夜有，听见了，就当旧脉在应。」「……别多问，到了水段再讲。」 |
| 离线留言 | 「断锚屑收好了，脉上无新痕，勿念。」「凿的是要拴住的东西，不是要挖的东西。回来教你认。」 |

## 四、N4 · 薇拉（蚀纹学者）

> 弧线锚：提出"蚀纹是被写出来的"，然后亲手证伪自己的一半。**互文锚**：立论「有稿，就有手」→修正案「有稿，无手」／对照观测点只记录不讨伐／卡戎断锚屑样本并卷（N04_薇拉（新）.md 转折—收束段）。

| 场景 | 台词 |
|:---|:---|
| 初见 | 「先声明，我立过错论，当众改的那种。」「所以别信我说的，信拓样。」 |
| 委托 | 「观测点只记录、不讨伐。」「整潮一拓，误差记到小数位——你手稳，来。」 |
| 闲聊 | 「『有稿，无手』。这一叉是我自己画上去的，画得心甘。」「档案并卷了，断锚屑那宗就排在我案头，线索不认人，只认笔迹。」 |
| 离线留言 | 「新拓一版，仍与旧稿同笔迹。」「无新结论，即是结论。」 |

| 离线留言 | 「换气口无风，潮平。」「册子我合着，等你回来对页。」 |

## 六、N6 · 塔奇（云帆号舵手）

| 场景 | 台词 |
|:---|:---|

| 委托 | 「这趟走雨廊外沿。」「教你一手：预读落点，先看雨檐——学会了，没有仪器也丢不了船。」 |
| 闲聊 | 「暗格里收着一页笺、一个结。等哪天有人回来，得让他看见这一手还在。」「折笺的手法教你一遍，学不学随你，船骨换三茬，这个不变。」 |
| 离线留言 | 「风窗两日稳，舵轮我养着。」「你回来正好赶上换肋材。」 |

## 七、N7 · 塞菈（巡游公会调度员）

| 场景 | 台词 |
|:---|:---|
| 初见 | 「报编号、报航线、报归期。」「三样齐了，我把你写进今日点卯——回来一个，划掉一个。」 |

| 闲聊 | 「名单墙上那行空行，我贴回去了。它现在不留给回不来的人，留给今天出去的人。」「调度不是指挥谁，是保证你回来时，有人看着灯。」 |
| 离线留言 | 「本台不睡，灯不灭。」「归期过了半个时辰，再过半个，我去接。」 |
