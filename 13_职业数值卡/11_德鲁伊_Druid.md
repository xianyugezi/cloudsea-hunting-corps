## 1 · 职业概览

| 项 | 值 |
|---|---|
| 中文名 / 英文名 | 德鲁伊 / Druid |
| emoji / 群内指令 | 🌿 / `德鲁伊2` |
| 定位 / 节奏 | 共生灵标记·空中 / 中·控制 |
| 偏好武器 | **法杖** `WPN.STAFF`（单段 · 近战/空中 · G×T 26） |
| 专属资源 | **孢子 Spore**（0–3，共生杖战技可提至 5） |
| 核心特色 | **改写部位硬度矩阵本身**——别人在矩阵里选解，它改矩阵 |
| 生态位 | 唯一能让"打不动的硬部位"变成全队可打目标者；全队命中的唯一来源 |
| 队伍当量 | 主控 1.0 + 共生灵 0.1（`$C.BALANCE.PARTY_COEFFICIENT` = 1.6） |

**一句话**：别的职业在巨兽的硬度矩阵里挑最软的部位打；德鲁伊直接**把某个部位的硬度改软**，再让全队一起打。它是全游戏唯一一个"输出=给队友造输出环境"的职业。

**与相邻职业的分界（关键，必须划清）**：

| | 德鲁伊 | 吟游诗人 | 圣骑士 |
|---|---|---|---|
| 增益载体 | **敌人身上的部位标记** | **队友身上的 Buff** | **队友手里的道具** |
| 增益性质 | 改变**敌人受击面**（H / 破坏槽 / 命中） | 改变**队友输出乘区**（D 侧） | 改变**队友行动资源**（不占回合） |
| 是否可被驱散 | 标记挂在敌人身上，**不会被驱散** | 可被敌方驱散 | 道具已交付，不可回收 |
| 依赖预判 | 高（须战前猜对打哪个部位） | 低（全队通用） | 中（要猜谁需要） |
| 生态位 | 唯一**改矩阵** | 唯一**换乘区** | 唯一**送回合** |

> **这张卡最需要警惕的问题**：德鲁伊的收益**大部分在队友身上**，若按"个人裸 DPR"评估会严重低估，若按"全队增益全额计入"又会高估（多人带增益时重复计）。第 9.3 节的**团队增益 55% 折算系数**是本卡最关键的口径约定。

## 2 · 专属资源：孢子 Spore（0–3）

### 2.1 资源定义

| 项 | 值 |
|---|---|
| 区间 | `0 – 3`（共生杖战技 +2 → `0 – 5`） |
| RU 换算 | 1 孢子 = `$C.RES.RU_FULL` ÷ 3 = **33.3 RU** |
| 主来源 | **杖击命中已标记处** +1（自主） |
| 次来源 | 敌人每次异常触发自动采集 +1（`$C.E.SYMBIONT_GATHER_INTERVAL` 每 2 回合上限 1） |
| 消耗点 | 投喂 / 抗性 / **孢爆**（本卡新增，见 2.3） |
| 受击 | **不扣**（孢子不受伤害影响） |
| 战斗结束 | 清零，不跨局 |
| 溢出保护 | **P3 满胞自动投喂**：孢子满且无消耗计划时，共生灵自动投喂当前积蓄最高的异常条 |

### 2.3 消耗途径（三个出口，**全部常驻可选**）

| # | 出口 | 消耗 | 效果 | 占回合 | 备注 |
|---|---|---|---|---|---|
| **C1** | **孢爆** Spore Burst | 1 孢子 | M **2.20**；若目标处于标记态，破坏槽 **×1.5** | ✅ 占 | ★ **本卡新增的输出出口** |
| **C2** | **投喂** Feed | 1 孢子 | 指定异常 **+`$C.E.SYMBIONT_FEED_ACCUM`**（80）积蓄 | ❌ 不占 | 共生灵自动执行；**唯一"调度异常"手段** |
| **C3** | **抗性** Resist | 1 孢子 | 全队该异常抗性 **+`$C.E.SYMBIONT_RESIST_BUFF`**（50%），3 回合 | ❌ 不占 | 共生灵自动执行 |

> **为什么必须有 C1（孢爆）**：设计稿原案中孢子的出口只有 C2/C3 两个**纯辅助**出口，这意味着德鲁伊的孢子**永远换不成自己的伤害**。结果是——德鲁伊的个人裸 DPR 只有约 0.58，全部收益都挂在队友身上，一旦单挑（同行兽被拆 / 单人推图）就彻底失去输出手段。
> **C1 是"辅助职业也该有自己的拳头"这条原则的落地**，与守卫的"释能斩"、骑士的"守势突刺"同理。

### 2.4 共生灵标记 Symbiont Mark

> **本卡的关键口径修正（务必阅读）**：
> 设计稿 `02 §2.2.11` 与常量表 `$C.E.SYMBIONT_MARK_HARDNESS` 均写作「**H −0.20**」。但在 `01 §M1.2` 的伤害公式中，**H 是伤害乘区**（区间 `$C.BATTLE.HARDNESS_MIN/MAX` = 0.35–1.80，**值越大＝部位越软＝伤害越高**；前爪·甲壳 H 0.75 是硬部位，头冠·晶核 H 1.45 是软部位，破坏后 H **+0.25~0.45** 也正是"打碎了更好打"）。
> 在 H 为伤害乘区的口径下，标记若写 `H −0.20` 会**降低**全队伤害，与生态位"改写部位硬度矩阵、让硬部位变可打"完全相反。
> **本卡采用的统一表述**：标记削减的是**硬度抗性 HR**，等效于**打击系数 H 提升**。数值保留原案的 0.20 / 0.25，方向修正为 **H +0.20（本命 +0.25）**。
> → 已登记为**待裁决项 W-03**（见附 A），建议同步修订 `12_全局常量表.md` 与 `02 §2.2.11` 的措辞，避免出现"数值对、方向反"的实现事故。

| 项 | 值（通用 / **本命**） |
|---|---|
| 硬度抗性削减 | `HR −0.20` → 等效 **H +0.20** / **本命 H +0.25** |
| 破坏槽 | **+`$C.E.SYMBIONT_MARK_BREAK`**（+25%） |
| 全队命中 | **+`$C.E.SYMBIONT_MARK_ACC`**（+10%） |
| 持续 | `$C.E.SYMBIONT_MARK_DURATION` **3 回合** / **本命 4 回合** |
| 换目标延迟 | `$C.E.SYMBIONT_SWAP_DELAY` = 1 回合 |
| 释放方式 | **战前编串，战内由共生灵自动执行，不占玩家回合** |

**编串指令示例**：`灵:标背脊→喂爆燃→抗沉眠`
（战前一次设置；战斗中共生灵按串自动跑，玩家**零操作**——这是德鲁伊托管几乎无损的根本原因。）

### 2.5 收支平衡表（可复核）

以偏好武器**法杖**、本命（H +0.25 / 4 回合）、7 回合循环为例：

| 回合 | 动作 | M | 孢子变动 | 期末孢子 |
|---|---|---|---|---|
| T1 | 杖击 A1（命中标记处） | 1.30 | +1 | 1 |
| T2 | 杖击 A1 | 1.30 | +1 | 2 |
| T3 | **孢爆 C1** | 2.20 | −1 | 1 |
| T4 | 升空 B1 | 1.00 | — | 1 |
| T5 | 空中杖击（H +0.20） | 1.30 | +1 | 2 |
| T6 | 俯冲 B3（压制 +30） | 2.00 | +1（G5） | 3 |
| T7 | 杖击 A1 | 1.30 | +1（满 3 → **P3 自动投喂**） | 3 → 自动投喂 −1 |

**循环长度 7 回合**，产孢 6、耗孢 2（1 次孢爆 + 1 次自动投喂），**净盈余 +4 → 由 P3 持续变现为异常积蓄**，不空转。

### 2.6 自动保护三律（防死锁 / 防溢出）

| 律 | 规则 | 解决的风险 |
|---|---|---|
| **P1 主来源自主** | G1「杖击命中标记处 +1」完全不依赖敌人行为 | 基础保障：即使敌人免疫所有异常（G2 完全失效），孢子照样攒 |
| **P2 孢囊律** | 连续 3 回合零采集 → 保底 +1 | 解决**异常压制局的收益空窗**：敌人抗性高时 G2 长期不触发 |
| **P3 满胞自动投喂** | 孢子满且战前串已跑完 → 共生灵自动投喂当前积蓄最高的异常条 | 解决**溢出浪费**：孢子满了没处花；同时也是**抗死锁**的第二保险 |

> **德鲁伊不存在真正的"死锁"**：孢子**不是任何行动的门槛**——杖击、孢爆、俯冲在孢子为 0 时**全部可用**。孢子是**纯盈余资源**，最坏情况只是"攒不到"，不会"动不了"。
> 这是 14 职业中死锁风险**最低**的一档（与剑客、盗贼同级）。

### 2.7 托管下的自动管理

| 场景 | 托管行为 |
|---|---|
| 常规 | 按战前 `1`/`2`/`3` 优先级；**共生灵编串全自动，不受托管影响** |
| 标记即将到期 | 共生灵**自动续标同一部位**（战前规则 `标 自动续`） |
| 孢子 ≥ 2 且目标异常条 < 阈值 60% | 自动投喂（战前规则 `喂 阈值`） |
| 目标挂 🌀（前摇意图） | 自动改走抗性（战前规则 `抗 前摇`） |
| 血线 < 40% | 自动走保底位「静默守」，延迟俯冲 |
| 超时 30 分钟 | 按战前预案 ①，孢子与标记剩余回合数随快照保存，跨天不重置（`$C.ASYNC.CROSS_DAY`） |

> **托管/在线 TTK 比 = 1.10**（全职业最优档之一）。原因：德鲁伊的**全部独特机制（编串、标记、投喂、抗性）都是战前配置、战内自动执行**，托管几乎不损失信息量。

### 2.8 死锁自检结论

> ✅ **不死锁，且为 14 职业中风险最低档。**
> - 孢子**不作为任何行动的门槛**（0 孢子时杖击 / 孢爆 / 俯冲全部可用）；
> - 主来源 G1 **完全自主**；
> - 出口 C1/C2/C3 **三个常驻可选**，不存在"想花花不掉"；
> - 最坏情况（敌人全异常免疫 + 全程零破坏）：仅 G1/G5/G6 生效，孢爆频率由约 3 回合/次降至约 4.5 回合/次，DPR 衰减至约 **0.94**——**仍在红线带内，且不崩溃**。
> - 196 组合 × 5 流派 = 980 格，**全部可解**。

## 6 · 本命词条（唯一一条）

> **本命**：装备**法杖**时，共生灵标记的两项参数同时提升——
> ① **标记持续 3 → 4 回合**
> ② **硬度抗性削减 −0.20 → −0.25**（等效 **H +0.20 → H +0.25**）

**为什么是这一条**：

- 它同时强化**覆盖时间**与**削减强度**，且两者**乘性叠加**：4 回合 × 0.25 的覆盖当量是 3 回合 × 0.20 的 **1.67 倍**。这是德鲁伊本命收益偏高的直接原因（见 9.4）。
- 它**不影响孢子获取**（孢子只看"是否命中标记处"，不看削减强度），因此**不会削弱抗死锁能力**。
- 它是**加法而非乘区**：H 是伤害公式中的独立层（`01 §M1.2`），标记把它从 1.10 拉到 1.35，是 **+22.7% 的部位伤害**，不会被其他乘区稀释，也不会出现"叠满后崩坏"。

**为什么不选"孢子 +1"或"孢爆倍率 +X%"**：孢子是**纯盈余资源**（非门槛），加强孢子获取不会改变任何决策；孢爆倍率是**个人乘区**，会让德鲁伊从"团队增益职业"滑向"伪输出职业"，与生态位冲突。把本命放在**团队增益的强度**上，才是对"辅助即输出"这一核心主张的忠实表达。

**换算**：标记覆盖当量 ×1.67，折算团队增益 **+0.075**、个人 **+0.021**，合计约 **+0.096**（见 9.4 本命/非本命落差）。

**跨档观察（本卡最关键的两段）**：

- **德鲁伊是对武器"段数"最不敏感的职业之一，但对"总注入量"高度敏感。**
  孢子的主来源 G1 是「**杖击命中标记处 +1**」，按**每次行动**结算而非每段。因此多段武器（双刃 4 段）**不会**让孢子涨 4 倍，单段武器（巨剑）**不会**让孢子慢 4 倍——注入差异全部来自 `G×T`。
  → 这解释了矩阵的走向：**巨剑 32 是本命法杖（32.5）之外的实际最优解**，两者几乎持平。这是"同源档 3/3 战技位"这一规则的自然结果，不是失衡。

- **轻弩 G×T 18 是唯一的红线风险点**，`WKR = 18 / 26 = 0.692`，**低于红线 0.82** ⚠️
  → **补偿设计**：德鲁伊装备**远程带武器**（轻弩 / 重弩 / 长弓）时，孢子注入追加 `段数 × $C.CLASS.DRUID.SPORE_RANGED_SEG_BONUS`（**1.4 RU/段**）。
  → 轻弩：`18 + 3 × 1.4 = 22.2` → **WKR 0.854** ✅
  → 重弩：`22 + 1 × 1.4 = 23.4` → WKR 0.900 ✅　长弓：`26 + 1.4 = 27.4` → WKR 1.054 ✅
  → 合理性：远程职业无法用"承伤"换资源，且**无法进入滞空的近战判定**（滞空 H +0.20 在远程带仍生效，但压制 ×1.5 失效），需要更高的自主注入速率补偿。

## 9 · 平衡自检表

### 9.1 DPR 口径声明（可复核）

```
EPM  = Σ(M × 命中率) × 暴击期望 ÷ 循环回合数
DPR  = EPM × $C.BALANCE.DPR_ANCHOR_COEF
```
**锚点系数**：`1.030 ÷ 2.256 ≈ 0.4566`（源自剑客 EPM 2.256 / DPR 1.030，与 `04`–`10` 各卡同口径）。

**团队增益折算约定**：德鲁伊的收益大量落在队友身上。为避免"多人带增益时重复计入"，团队受益类增益统一按 **55%** 折算入本职业 DPR（`$C.BALANCE.SUPPORT_CREDIT_TEAM`，见 `12` §I）。

> **W-05 复核结论（本卡数值不变）**：德鲁伊的四项团队增益（标记 H / 全队命中 / 破坏槽 / 异常调度）**全部属团队受益口径**，一律适用 `SUPPORT_CREDIT_TEAM` 0.55，无主控份额需拆分。故本卡**无需任何回溯校准**，1.039 保持有效。
> ⚠️ 本卡的"折算率"与"队伍系数 ×1.6"是**两层不同的东西**：前者防重复计数，后者衡量增益覆盖的当量范围，两者相乘（1.6 × 0.55 = 0.88 有效系数）。

## 附 B · 关键设计判断（五条）

1. **W-03 的方向修正不是文字游戏，是防实现事故。** 「H −0.20」如果被程序员照抄进代码，德鲁伊的标记会**降低**全队伤害 18%，而这个 bug 在数值评审时极难发现——因为"标记"听上去就该是个正面 buff，测试时看到数字变了往往默认是对的。**凡是"符号方向与直觉相反"的数值，必须在常量表里写成公式而不是标量**（如 `MARK = {op:"add", layer:"H", value:+0.20}`），这是 N4 条件 DSL 之外的另一层保险。

2. **C1 孢爆是这张卡能不能成立的开关。** 原案的德鲁伊个人裸 DPR 只有约 0.58，全部价值挂在队友身上。这在 4 人固定队里没问题，但在 QQ 群异步场景里，玩家**大量时间是单人 + 同行兽**在推图——一个"单人时没有拳头"的职业会被直接弃用。孢爆的 M 2.20 不高，但它让德鲁伊在**任何时候都能把自己攒的资源变成自己的伤害**。这条原则应当推广：**任何以团队增益为主轴的职业，都必须有一个把资源兑换成个人伤害的出口。**

3. **本命落差 0.120 偏大，但这次我选择不动它。** 通常这会是我的调整对象，但德鲁伊的非本命路线（巨剑 32 / 战斧 30 的"标记—重砸"）本身就是设计稿点名的话题组合（`02 §2.4` 跨武器组合示例第 1 条）。把本命削平只会让法杖变成唯一解，反而消灭了这个话题。**保留落差，靠"非本命路线也很有趣"来抵消，比靠数值抹平更健康。**

4. **滞空对德鲁伊不是位移手段，是第二个输出姿态。** 常驻滞空 = 常驻 H +0.20 + 压制 ×1.5，这让它成为御风流三大压制发动机之一（`02 §2.4` 表第 4 行）。但也正因如此，**德鲁伊 × 御风流的强度高度依赖"敌人是否会被滞空压制"**——遇到浮空类巨兽（本作世界观是空岛题材，浮空 Boss 占比不低）时收益会显著下滑。已在 9.5 登场率预估（9.6%）中留了余量，若实测跌破 6%，优先**投放地面友好的巨兽机制**而非回调数值。

5. **托管 TTK 比 1.10 是这张卡被低估的价值。** 德鲁伊的全部独特机制——编串、标记、投喂、抗性——**都是战前配置、战内自动执行**。在一个"玩家随时可能掉线 30 分钟"的 QQ 群异步场景里，这意味着德鲁伊是**唯一几乎不因托管而损失战力的职业**。对上班族玩家（本作的核心人群）而言，这比多 5% 的 DPR 有价值得多。
