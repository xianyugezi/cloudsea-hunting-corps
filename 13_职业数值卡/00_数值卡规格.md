# 职业数值卡 · 统一规格（14 张卡共同遵守）

> 本文件是 14 张职业数值卡的**格式契约**。每张卡独立成文、可单独阅读，但字段、顺序、命名必须与本规格一致。
> 前置必读：`../11_架构与模块化规范.md`（模块化与无硬编码）、`../12_全局常量表.md`（所有共享数字）、`../02_职业×流派×武器解耦.md`（职业与武器解耦规则）。

## 二、九段结构（顺序固定，缺段即不合格）

| # | 段名 | 内容要求 |
|---|---|---|
| 1 | 职业概览 | 中文名 / 英文名 / emoji / 群内指令 / 定位 / 节奏 / 偏好武器 / 专属资源名 / 核心特色一句话 / 生态位一句话 |
| 2 | 专属资源 | 名称、区间、**逐条**获取途径、**逐条**消耗途径、RU 换算、自然增长、受击变化、清零规则、**死锁自检结论** |
| 3 | **基础动作表（全量）** | 偏好武器的**每一个**基础动作，逐行列出 |
| 4 | **战技表（全量）** | 全部战技，含主/副/保底三个战技位的**所有可选战技** |
| 5 | 绝技表 | 战斗 / 游击 / 防御 三类，每类 ≥1 个 |
| 6 | 本命词条 | 装备偏好武器时额外生效的**唯一一条**词条 |
| 7 | 五流派适配 | 每流派：加成机制、DPR 期望、得、失、推荐度（★1–5） |
| 8 | **14 武器适配矩阵** | 本职业 × 14 武器逐行：档位、RU/回合、战技位数、走法一句话 |
| 9 | 平衡自检表 | DPR、登场率、TTK 比、托管可玩性、资源死锁、差异化证明、红线符合性 |

## 三、基础动作表字段（第 3 段）

| 字段 | 说明 |
|---|---|
| 动作名 | 中文名（原创、无版权风险） |
| 倍率 M | 数值，遵守 `$C.BATTLE.MULT_M_MIN/MAX`（0.6–3.2） |
| 段数 | 1 / 多段（注明的段数） |
| 占回合 | 1，或 2（如蓄力重击） |
| 异常值 V | 若该动作可挂载异常，给出 V；无则写 — |
| 破坏槽贡献 | 基础值，或 `N × $C.BREAK.*` |
| 资源注入 | 注入多少 RU（或专属资源单位 + 换算 RU） |
| 位移 | 是否位移 / 消耗风缆 |
| 备注 | 特殊规则（如"无视部位硬度""需蓄力阶 ≥2"） |

> **全量要求**：不得只写"等 3 个代表动作"。玩家在战前能看到的所有动作都要在表内，且每个动作都要能填进 `1`/`2`/`3` 的指令位体系。

## 四、战技表字段（第 4 段）

| 字段 | 说明 |
|---|---|
| 战技名 | 中文名 |
| 战技位 | `主` / `副` / `保底`（保底位须包含：防御 / 符文道具 / 换位 三类） |
| 倍率 M | |
| 附加效果 | 位移、护盾、净化、异常挂载、破坏加成、资源变动等 |
| 消耗 | 风缆 / 专属资源 / 绝技槽 / 无 |
| 前置条件 DSL | 用 `when:` 表达式，见 §11.4 N4（无前置则写 `—`） |
| 流派变体 | 五个流派下此战技的差异（追加段 / 倍率 / 限制） |

## 五、硬约束（违反即打回）

1. **无硬编码**：所有共享数字写 `$C.域.名` 引用常量表；只有本职业专属数值可直接写数字。
2. **零数值惩罚**：本职业 × 非偏好武器时，**不得**出现 ATK / 倍率 / 暴击 / 绝技槽数的减法。差异只能是"资源注入速度 × 战技位开放数 × 有无本命"三项的**正向收益多少**。
3. **资源单调可解**：专属资源必须满足「**能单调累积 + 有单一明确消耗点 + 有自动保护**」，保证 196 组合在超时托管下**永不死锁**（`§11.8` 检查项 8）。
4. **异步可玩**：所有机制必须在**战前可配**、**战内自动执行**；不得设计需要实时反应的操作。
5. **术语一致**：一律使用第 0 章术语表（七属性、九异常、五流派、风缆、绝技、共生灵、同行兽、丰饶符等）。
6. **原创命名**：动作与战技名全部原创，禁用任何在先作品的招式名、武器名、机制名（含音译）。
7. **可拆性声明**：卡末须注明「本职业依赖哪些 L1 模块（软/硬）」，若 `S07 绝技` 或 `S12 同行兽` 被拆除，本职业如何降级。

## 六、平衡红线（卡内自检表必须逐条给结论）

| 项 | 红线 |
|---|---|
| 职业 DPR 带 | `0.92 – 1.08`（相对全职业均值） |
| 流派 DPR 差 | `±8%` |
| 登场率 | `4% – 18%` |
| 托管/在线 TTK 比 | `≤ 1.35` |
| 本命组使用率（全武器层） | `45% – 70%` |
| 队伍系数 | `1.6`（主控 1.0 + 同行兽 2×0.5~0.7 + 共生灵 0.1） |
