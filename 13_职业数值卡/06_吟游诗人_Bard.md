## 2 · 专属资源：乐章值 Movement（0–3，本命 0–4）

### 2.1 资源定义

| 项 | 值 |
|---|---|
| 名称 | 乐章值（Movement，记 `MV`） |
| 区间 | `0 – 3`（常态）／ `0 – 4`（装备号角触发本命词条「满谱」，见第 6 段） |
| RU 归一 | 条满恒 = `$C.RES.RU_FULL`（100 RU） |
| 单位换算 | 上限 3 → `1 MV = $C.RES.RU_FULL ÷ 3 ≈ 33.3 RU`；上限 4（本命）→ `1 MV = $C.RES.RU_FULL ÷ 4 = 25 RU` |
| 自然增长 | **0**（无自然回复；靠动作注入，防"挂机自动满条复读"） |
| 受击变化 | **不扣减**。乐章是"已写好的谱面"而非怒气，受击不影响 |
| 打断返还 | 演奏前摇被 🌩️雷殛作废时，**已支付乐章全额返还**（自动保护律 ②） |
| 清零规则 | ① 支付演奏消耗（按量扣减，非清零）；② 收束（尾声）回收后归零；③ 战斗结束；④ **跨阶段不重置**（乐章非异常积蓄，不走 `$C.AILMENT.PHASE_INHERIT`） |
| 每回合期望注入 | `G × T × 档位系数` RU；满条行动数 `N = $C.RES.RU_FULL ÷ (G×T × 档位系数)` |

### 2.2 获取途径（逐条）

| # | 途径 | 注入量 | 频率 | 说明 |
|---|---|---|---|---|
| G1 | **谱曲·起调**（`ACT.HORN.A1`） | +2 MV | 每次 | 占 1 回合，本回合不执行武器攻击（代价见 §2.5） |
| G2 | **谱曲·续谱**（`ACT.HORN.A2`） | +2 MV；若上回合亦为谱曲则再 +1 | 每次 | 连谱奖励，鼓励"两回合写满谱" |
| G3 | **谱曲·采风**（`ACT.HORN.A3`） | +1 MV | 每次 | 位移后谱曲，兼走位（可躲 🌀 范围轰击） |
| G4 | **谱曲·默记**（`ACT.HORN.A4`） | +1 MV，且下次演奏消耗 −1 MV（下限 1 MV） | 每次 | 长局保底，防"乐章不足空过" |
| G5 | **命中注入**（任意伤害动作命中） | +1 MV | **每回合 1 次** | **职业级规则，跨武器恒定**；非号角武器下诗人的主注入源 |
| G6 | **余韵**（`ACT.HORN.D2`，自动） | +1 MV | 乐章自然到期时 1 次 | 自动保护律 ③，等价于"结束时返还"，**非自然增长** |
| G7 | **掩息 / 静默休止**（保底位防御动作） | +1 MV | 每次 | 防御回合不空过，乐章照涨（零收益回合率压制手段） |

### 2.3 消耗途径（**单一明确消耗点**）

> **唯一消耗点 = 「演奏」**（`perform`）。系统内只有**一个**扣减函数 `pay_movement(n)`，三处调用共用同一规则，故视为单一消耗点。

| # | 调用方 | 支付量 | 说明 |
|---|---|---|---|
| P1 | **主谱演奏**（战歌 / 守歌 / 疾歌） | 1 MV | 主战技位，全队增益 3 回合 |
| P2 | **重奏**（副战技位：续奏 / 叠奏） | 1 MV | 续期 + 叠层 |
| P3 | **收束**（尾声，回收全部剩余乐章） | 剩余全部 MV | 主动结束乐章，回收量转尾声尾伤 |

**统一支付规则**：`MV < n` 时**不允许支付**，改为自动降级（§2.6 保护律 ①）。任何分支都不出现"付一半"或"负值"。

### 2.4 乐章存续 / 重奏刷新规则

| 项 | 规则 |
|---|---|
| **乐章持续时间** | 主谱演奏后 **3 回合**（自演奏当回合起算）；守歌、疾歌同为 3 回合 |
| **重奏刷新规则** | 存续期内再奏**同一谱** → ① 存续**重置为 3 回合**（不是延长叠加，避免无限滚雪球）；② 叠 **1 层**，基础上限 **2 层**，第 2 层效果 `×0.70`（衰减 30%） |
| **叠层上限** | 基础 2 层；副位选「叠奏」变体 → 上限 **3 层**，第 3 层 `×0.49`（每层 −30%） |
| **切谱规则** | 演奏**不同**谱 → 原乐章立即进入尾声（自动触发收束，回收剩余 MV），不叠加、不冲突 |
| **回合末结算序** | ① 乐章持续 −1 → ② 持续归 0 则触发余韵（+1 MV）→ ③ 余韵后若 `MV ≥ 1` 且战前预案开「自动续奏」，则**下一回合自动演奏战前指定主谱** |
| **同时生效谱数** | 主谱 1 个（主位 3 选 1）；协奏（破甲谱 / 侵蚀谱）为**自动附加**，不占谱位 |

### 2.5 谱曲占回合的代价

| 项 | 说明 |
|---|---|
| **代价内容** | 谱曲回合**不执行武器攻击**，损失该武器 1 个行动的 `ATK × M × H × E × …` 全额产出 |
| **已计入 T** | 号角 `T = 0.60`（`02 §2.2.15` 表注明"谱曲不出伤"），即谱曲折损已内建在号角的注入效率里 |
| **跨武器差异** | 谱曲是**职业级动作**，任何武器可用；代价随武器 ATK 放大——<br>**慢械（巨剑 / 战锤）谱曲代价高** → 倾向"打完再谱"；<br>**快械（双刃 / 轻弩）谱曲代价低** → 倾向"先谱满再打"。<br>这是**解耦带来的走法差异**，不是数值惩罚（三档注入系数恒为 1.00 / 1.25） |
| **回本门槛** | 谱曲 1 回合（+2 MV ≈ 1 次主谱演奏）在 **≥4 回合**的战斗中回本；故诗人在 TTK 2–3 的浮岛杂兽局收益为负，在 TTK ≥8 的上位 / 蚀潮局收益最大（与 `$C.BALANCE.WINDOW_CONTRIB_MIN` 同向） |

### 2.6 自动保护三律（防死锁）

| # | 律 | 内容 |
|---|---|---|
| ① | **不足自动降级** | `MV ≥ 1` → 奏 **1 乐章简谱**（效果 `×0.60`，持续 2 回合，仍计入重奏叠层）；`MV = 0` → **自动执行「起调」谱曲**（永不空过） |
| ② | **打断全额返还** | 演奏前摇被 🌩️雷殛 / 💫麻痹作废 → 已支付 MV 全额退回，乐章不进入尾声 |
| ③ | **到期自动返还** | 乐章持续归 0 → 自动触发「余韵」+1 MV → 下一回合按战前预案自动续奏 |

### 2.7 托管下的自动续奏

**代打决策序**（`02 §2.5.3` 给定 + 本职业细化）：

```
1. 乐章 < 2                    → 谱曲（起调 / 续谱，优先续谱拿 +1）
2. 乐章 ≥ 2 且无生效乐章        → 演奏战前预案指定的「主谱」
3. 生效乐章持续 ≤ 1 且 乐章 ≥ 1  → 重奏（续期 + 叠层）
4. 乐章 = 满 且 敌处倒地/异常窗口 → 收束（尾声，吃 Xa 易伤）
5. 血线 < 40%                  → 保底位（掩息 / 静默休止 / 应急符石）
```

**战前预案 DSL**（`11 §11.4 N4` 格式；托管 AI 与在线玩家走**同一套**求值器——这是 TTK 比 ≤1.35 的保障）：

```yaml
- id: bard_auto_score          # 乐章不足先谱曲（永不空过）
  when: { op: "<", left: "$resource.movement", right: 2 }
  then: { action: "compose", variant: "sustained_phrase", slot: "FREE" }

- id: bard_auto_perform        # 无生效乐章则按战前谱面演奏
  when: { op: "==", left: "$buff.active_strain.layers", right: 0 }
  then: { action: "perform", slot: "MAIN", pay: 1 }

- id: bard_auto_reprise        # 存续将尽自动续奏
  when: { op: "<=", left: "$buff.active_strain.duration", right: 1 }
  then: { action: "perform", variant: "reprise", slot: "SUB", pay: 1 }

- id: bard_auto_coda           # 窗口期收束，吃异常易伤
  when: { op: ">=", left: "$enemy.xa_vuln", right: "$C.AILMENT.X_VULN_MIN" }
  then: { action: "coda", slot: "SUB" }

- id: bard_auto_guard          # 血线兜底
  when: { op: "<", left: "$self.hp_ratio", right: "$C.CLASS.BARD.ITEM_HP_THRESHOLD" }
  then: { action: "cover_breath", slot: "SAFE" }
```

> **要点**：五条全部是**阈值判断 + 自动执行**，战前设一次即可。玩家在线时若发 `1`/`2`/`3`，该回合以玩家指令优先，下回合回到预案。

### 2.8 死锁自检结论

| 检查 | 结论 |
|---|---|
| 资源是否单调累积 | ✅ 外部事件（受击、驱散、阶段转换）**均不扣减**乐章；唯一减少点是演奏支付，且支付前必有 `MV ≥ n` 校验 |
| 是否有单一明确消耗点 | ✅ 仅 `perform`（主谱 / 重奏 / 收束三个调用方共用 `pay_movement(n)` 同一规则） |
| 是否有自动保护 | ✅ 三律齐全（不足降级 / 打断返还 / 到期返还） |
| 196 组合 × 5 流派 = 980 格是否全可解 | ✅ **谱曲是职业级动作，不占战技位**，故即便近邻 / 跨域档位把战技位压到 2/3，G1 谱曲与 G5 命中注入**依然可用**；`MV = 0` 时保护律 ① 强制谱曲，不存在"无招可出"状态 |
| 超时托管是否空过 | ✅ 代打序第 1 条即谱曲；`$C.ASYNC.CUSTODY_AFTER_TURNS` 后代打按同一序执行 |
| 与 `$C.BATTLE.TTK_HARD_CAP` | ✅ 最慢组合（轻弩 `G×T 18`）`N = 5.56` 次行动满条，仍在 40 回合硬顶内完成 ≥7 个完整谱面循环 |

**结论：乐章值满足「单调累积 + 单一明确消耗点 + 自动保护」三律，196 组合 × 5 流派在超时托管下永不死锁（`11 §11.8` 检查项 8 通过）。**

### 9.3 双行算式（辅助职业必给）

```
【口径】全职业均值 = 1.00；主控位当量 1.0
        队伍当量 = $C.BALANCE.PARTY_COEFFICIENT = 1.60
                （主控 1.0 + 同行兽 $C.BALANCE.COMPANION_EQUIV 0.5 + 共生灵 $C.BREAK.SYMBIONT_EQUIVALENT 0.1）

① 个人 DPR（含自身增益；自身仅享 55%）
   = 个人裸 DPR × (1 + G × $C.CLASS.BARD.SELF_GAIN_FACTOR)
   = 0.683 × (1 + 0.276 × 0.55)
   = 0.683 × 1.1518
   = 0.7867

② 团队增益折算当量（**已套 `SUPPORT_CREDIT_TEAM` 0.55**，W-15 收口）
                   = G × 队伍当量 × SUPPORT_CREDIT_TEAM − 扣重项
                   = G × $C.BALANCE.PARTY_COEFFICIENT × 0.55 − G × SELF_GAIN_FACTOR × 个人裸 DPR
                   = 0.276 × 1.60 × 0.55 − 0.276 × 0.55 × 0.683
                   = 0.2429 − 0.1037
                   = 0.1392      （扣重项 = ① 中已计入的自身增益，避免重复计算）

③ 综合当量 = ① + ② = 0.7867 + 0.1392 = 0.9259 ≈ 0.926
```

> **化简校验**：② 的扣重项与 ① 的自身增益项严格相消，故 `综合当量 ≡ 个人裸 DPR + G × 队伍当量 × SUPPORT_CREDIT_TEAM = 0.683 + 0.276 × 1.60 × 0.55 = 0.683 + 0.2429 = 0.9259`。后续各表均用此化简式，**不存在双重计数**。

> ✅ **W-15 已收口 · 豁免收回（本卡现统一适用 `SUPPORT_CREDIT_TEAM` 0.55）**

### B.2 若 `S07 绝技` 被拆除

| 项 | 处置 |
|---|---|
| 直接变化 | 指令位 ② 移除；**战技位 2 → 3**（原 ③ 位可放战技，`11 §11.2` 降级规则）；5 个绝技全部失效 |

### B.3 若 `S12 同行兽` 被拆除（队友变少）

| 项 | 处置 |
|---|---|
| 直接变化 | 队伍系数 `$C.BALANCE.PARTY_COEFFICIENT` 1.60 → `$C.BALANCE.PARTY_COEFF_NO_COMPANION`（建议 1.10）；敌人 EHP ×= `$C.COMP.COMPANION.EHP_SCALE`（1.10 ÷ 1.60 = 0.6875）；「交叠换位」战技自动隐藏 |
| **增益重算（等比口径）** | 队伍当量 1.60 → 1.10，敌人 EHP 同比缩 0.6875 → **诗人的增益"占比"守恒**。<br>综合当量（比例口径）= `0.546 + 0.276 × 1.10 = 0.850`；同时敌人 EHP ×0.6875，等价于主控位输出需求下降 31.25% → 折算回同一基准：`0.850 ÷ (1 − 0.3125) = 1.236`… 该除法口径不成立，正确做法是**直接比较相对位置**：<br>拆除前：诗人队总当量 `= (0.546 + 0.6) × (1 + 0.276) = 1.461`；基准队 `= 1.000 + 0.6 = 1.600`（比值 **0.913**）<br>拆除后：诗人队总当量 `= (0.546 + 0.1) × (1 + 0.276) = 0.824`；基准队 `= 1.000 + 0.1 = 1.100`（比值 **0.749**） |
| **体验补偿（可选，非必需）** | 上表显示拆除后诗人的**相对位置从 0.913 掉到 0.749**（−16.4%），因为增益的固定幅度 G 不变而受益当量从 0.6 降到 0.1。按 `§11.5`"数值自动重算"要求，触发补偿：**拆除 `S12` 时，`$C.CLASS.BARD.SELF_GAIN_FACTOR` 由 0.55 临时提升至 0.90，且「大谱第 4 位」的 +8% 改为常驻 +16%**（`G = 0.276 + 0.017 = 0.293`） |
| 补偿后 | 诗人队总当量 `= (0.546 × (1 + 0.293 × 0.90) + 0.1) × (1 + 0.293)`…按化简式：`= 0.546 + 0.293 × 1.10 = 0.868`；基准队 1.100 → 比值 **0.789**（较 0.749 回升 5.3pt，接近但未完全回到 0.913） |
| 结论 | `S12` 拆除后诗人的**绝对**团队价值随队伍当量下降，**相对红线位置下滑约 16%**；按补偿后仍低约 12%。**建议处置**：`S12` 拆除时启用「独奏专精」降级分支——乐章改为**只作用于主控与共生灵但幅度 ×1.6**（`G → 0.44`），使 `0.546 + 0.44 × 1.10 = 1.030`，比值回到 `0.936 ≈ 0.913` ✅。**该分支纯数据实现（职业表加一行降级参数），不新增代码分支**，符合 `§11.4 N3 表驱动` |
