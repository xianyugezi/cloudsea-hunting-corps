## 2 · 专属资源：携行包 Satchel（0–3 格）

### 2.1 资源定义

| 项 | 值 |
|---|---|
| 名称 | 携行包（Satchel，记 `SL`），单位"格" |
| 区间 | `0 – 3`（常态；保底位「应急补给」可临时破上限至 4 格，1 回合） |
| RU 归一 | 条满恒 = `$C.RES.RU_FULL`（100 RU）→ **`1 格 = $C.RES.RU_FULL ÷ 3 ≈ 33.3 RU`** |
| 单位换算 | 上限 3 → 每格 33.3 RU；保底位超上限 4 格时，第 4 格为**临时格**，不参与 `÷3` 归一，回合末自动消失 |
| 自然增长 | **0（常驻）**。`02 §2.2.3` 的「每 2 回合 +1 格」在本卡落点为 **G3 应急整备**，仅在 `SL ≤ 1` 时启动（见 §2.6 保护律 ③ 与附 B 判断 5） |
| 受击变化 | **不扣减**。携行包是**实物道具**而非怒气/乐章——受击、驱散、异常、阶段转换均不减少格数。这是"单调累积"的第一重保障 |
| 打断返还 | 随附支援被 🌩️雷殛 / 💫麻痹作废时，**已支付格数全额返还**（保护律 ②） |
| 清零规则 | ① 支付随附支援消耗（按量扣减，非清零）；② 战斗结束；③ **跨阶段不重置**（实物道具不走 `$C.AILMENT.PHASE_INHERIT`） |
| 每回合期望注入 | 见 §2.5 收支平衡表：`≈ 0.78 格/回合`（本命剑盾另计返还） |

### 2.2 获取途径（逐条）

| # | 途径 | 注入量 | 频率 | 说明 |
|---|---|---|---|---|
| G1 | **整备槽**（武器通道） | 满 100 RU → **+1 格**并清零 | 持续 | **唯一随武器变化的注入源**。基础动作命中注入 `G×T × 档位系数` RU/回合 → `N = 100 ÷ (G×T × 档位系数)` 次行动整备 1 格（**2.50 – 5.56 次**，与全项目同口径） |
| G2 | **战术直注 · 连击** | **+0.5 格** | **每回合 1 次** | 剑盾连击命中触发。**不随段数放大**——2 段仍只 +0.5（附 B 判断 3） |
| G3 | **战术直注 · 格挡** | **+0.5 格** | 每回合 1 次 | 格挡（B3 / 保底位「铁扉格挡」）触发。与 G2 **共享每回合 0.5 格上限**（一回合只有一个主行动） |
| G4 | **应急整备**（自动） | **+1 格** | `SL ≤ 1` 时每 2 回合 1 次 | 保护律 ③。`02 §2.2.3`「每 2 回合 +1 格」的落点 |
| G5 | **破盾击命中**（副位 S1） | **+0.5 格** | 每次 | 副位选「破盾击」时的额外注入口，与 G2/G3 **不共享**上限 |
| G6 | **应急补给**（保底位符文道具） | **+1 格**（可破上限至 4） | 消耗 1 件道具 | 战前定序；`SL ≤ 1` 时托管自动取用 |
| G7 | **同行兽「搬运」支援**（`S12`） | **+0.5 格** | 每次 | 同行兽触发搬运类支援时附带（`S12` 拆除时本项自动隐藏） |
| G8 | **本命返还**（仅剑盾） | **+0.5 格** | 每次随附支援 | 本命词条「随行」，见第 6 段 |

### 2.3 消耗途径（**单一明确消耗点**）

> **唯一消耗点 = 「随附支援」**（`attached_support`）。系统内只有**一个**扣减函数 `pay_satchel(n)`，六件道具共用同一规则，故视为单一消耗点。

| # | 调用方 | 支付量 | 说明 |
|---|---|---|---|
| P1 | **取药**（药剂） | 1 格 | 回 18% HP（战前指定给"主控 / 同行兽中血线最低者"） |
| P2 | **净涤**（净化剂） | 1 格 | 清除 1 个异常（战前定优先级） |
| P3 | **撒粉**（破甲粉） | 1 格 | 本回合破坏槽 ×2 |
| P4 | **布陷**（陷阱） | 1 格 | 压制量表 +40 |
| P5 | **装弹**（异常弹） | 1 格 | 本回合命中同步挂载异常 V 55（战前选异常种类，按段分摊） |
| P6 | **投喂**（孢子投喂） | 1 格 | 共生灵目标异常积蓄 +`$C.BREAK.SYMBIONT_FEED_ACCUM`（80） |

**统一支付规则**：`SL < 1` 时**不允许支付**，改为自动跳过（保护律 ①）。任何分支都不出现"付一半"或"负值"。
**每回合硬上限**：随附支援**每回合最多取用 1 件**（`02` 未明示，本卡补齐，理由见附 B 判断 2）。同回合多件满足条件时，按战前定序取**优先级最高的 1 件**，其余留到下回合。

### 2.4 随附支援的触发与定序

| 项 | 规则 |
|---|---|
| **是否占回合** | **不占**。随附支援与主战技（或任何主行动）**同回合结算**，在主行动伤害结算**之后**触发（保证破甲粉能吃到本回合的破坏槽） |
| **是否占战技位** | **不占**。随附支援挂在**职业级行动层**，不进主 / 副 / 保底任何一个战技位——这是"强袭流③位锁续攻也不影响支援线"的结构原因 |
| **判定时机** | 主行动**开始前**求值一次 `when:`；成立则在主行动后结算。战内零操作 |
| **战前定序** | 每件道具一条 `when:` + 一个 `priority`（1/2/3）。例：`1 药剂<50% ｜ 2 净化（自身异常≥1）｜ 3 破甲粉（部位未破坏）` |
| **主战技绑定** | 主战技位（携行位）决定**包里能装哪几类道具**（3 变体 = 3 种包型，见 §4.1）；道具**种类与配比在包内自由选**，总数恒 3 件 |

### 2.5 收支平衡表（可复核）

> 口径：**本命剑盾**，`G×T 22 × $C.WEAPON.PREFERRED_GAIN（建议值 1.25） = 27.5 RU/回合`

| 项 | 计算 | 格/回合 |
|---|---|---|
| 整备槽（G1） | `27.5 RU ÷ 100 RU/格` | **+0.275** |
| 战术直注（G2 或 G3，二选一） | 连击或格挡，每回合上限 | **+0.500** |
| 应急整备（G4，`SL ≤ 1` 时） | `1 格 ÷ 2 回合` | **+0.500**（条件性） |
| 本命返还（G8） | `+0.5 格 × 0.85 次使用/回合` | **+0.425** |
| **本命剑盾 · 合计（常态）** | 0.275 + 0.500 + 0.425 | **+1.200** |
| **本命剑盾 · 合计（低储 `SL≤1`）** | 0.275 + 0.500 + 0.500 + 0.425 | **+1.700** |
| **非本命 · 合计（常态）** | 0.275×`(G×T/27.5)` ≈ 0.18–0.32 + 0.500 | **+0.680 – 0.820** |
| **消耗** | 每回合最多 1 件 × 触发率 | **−0.70 – 0.85** |

**结论**：本命净流 ≈ **+0.40 格/回合 → 常满 3 格（支援永续）**；非本命净流 ≈ **+0.025 格/回合 → 贴着 2 格呼吸**。这正是"本命是更优解"的量化来源，也是 §9.5 HPR 的核心依据。

### 2.6 自动保护三律（防死锁）

| # | 律 | 内容 |
|---|---|---|
| ① | **不足自动跳过** | `SL < 1` → 随附支援**整段跳过**，主战技照常执行（**退化为普通攻击，绝不空过**）；`SL ≥ 1` 但无一满足条件 → 同样跳过，格数保留 |
| ② | **打断全额返还** | 随附支援被 🌩️雷殛 / 💫麻痹作废 → 已支付格数全额退回 |
| ③ | **低储应急整备** | `SL ≤ 1` → 自动启动应急整备（每 2 回合 +1 格），不占行动、不需玩家操作 |

### 2.7 托管下的自动支援

**代打决策序**（`02 §2.5.3` 给定「血线 <50% 用急救包（不占行动）；否则剑盾连击」+ 本职业细化）：

```
1. 血线 <50% 且 包内有药剂/净化剂 → 随附支援取药（净涤）（不占主行动）
2. 包内 ≥1 格 且 有任一道具条件成立 → 随附支援取用优先级最高的 1 件
3. 携行包 ≤1 格 且 保底位含「应急补给」 → 取应急补给（+1 格）
4. 敌挂 ⚔️ 且 保底位可用        → 铁扉格挡（+0.5 格）
5. 其余                          → 主战技（携行位）连击
```

**战前预案 DSL**（`11 §11.4 N4` 格式；托管 AI 与在线玩家走**同一套**求值器——这是 TTK 比 ≤1.35 的保障）：

```yaml
- id: paladin_auto_vial              # 血线兜底：取药（不占主行动）
  when: { op: "<", left: "$party.min_hp_ratio", right: "$C.CLASS.PALADIN.ITEM_HP_THRESHOLD" }
  then: { action: "attached_support", item: "vial", slot: "FREE", pay: 1 }

- id: paladin_auto_cleanse           # 自身挂异常优先净化
  when: { op: ">=", left: "$self.ailment_count", right: 1 }
  then: { action: "attached_support", item: "cleanser", slot: "FREE", pay: 1 }

- id: paladin_auto_powder            # 破坏窗口：撒粉（本回合破坏槽 ×2）
  when: { op: "<", left: "$enemy.part_broken_ratio", right: 1.0 }
  then: { action: "attached_support", item: "sunder_powder", slot: "FREE", pay: 1 }

- id: paladin_auto_snare             # 压制将满：布陷
  when: { op: ">=", left: "$enemy.override_ratio", right: 0.70 }
  then: { action: "attached_support", item: "snare", slot: "FREE", pay: 1 }

- id: paladin_auto_resupply          # 低储自动补给
  when: { op: "<=", left: "$resource.satchel", right: 1 }
  then: { action: "emergency_resupply", slot: "SAFE" }

- id: paladin_auto_guard             # 敌挂重击则格挡（顺带 +0.5 格）
  when: { op: "==", left: "$enemy.intent.type", right: "HEAVY" }
  then: { action: "iron_door", slot: "SAFE" }
```

> **要点**：六条全是**阈值判断 + 自动执行**，战前设一次即可。玩家在线时若发 `1`/`2`/`3`，该回合以玩家指令优先，下回合回到预案。

### 2.8 死锁自检结论

| 检查 | 结论 |
|---|---|
| 资源是否单调累积 | ✅ 受击 / 驱散 / 异常 / 阶段转换**均不扣减**格数；唯一减少点是随附支援支付，且支付前必有 `SL ≥ 1` 校验 |
| 是否有单一明确消耗点 | ✅ 仅 `attached_support`（六件道具共用 `pay_satchel(n)` 同一规则） |
| 是否有自动保护 | ✅ 三律齐全（不足跳过 / 打断返还 / 低储应急整备） |
| 196 组合 × 5 流派 = 980 格是否全可解 | ✅ **随附支援是职业级行动层事件，不依赖任何战技位**。即便近邻 / 跨域档位把技位压到 2/3，六件道具与主战技**依然可用**；`SL = 0` 时保护律 ① 强制跳过支援、主战技照常输出，**不存在"无招可出"状态** |
| 超时托管是否空过 | ✅ 代打序第 5 条即主战技连击；`$C.ASYNC.CUSTODY_AFTER_TURNS` 后代打按同一序执行 |
| 与 `$C.BATTLE.TTK_HARD_CAP` | ✅ 最慢组合（轻弩 `G×T 18`）整备 1 格需 **5.56 次行动**，40 回合硬顶内可完成 ≥7 次完整整备；且应急整备（G4）保证 `SL ≤ 1` 时仍每 2 回合回 1 格 |
| **耗尽后是否退化** | ✅ 退化为**普通攻击**（主战技连击 M 1.40 原样执行），只失去支援附加，**不空过、不减伤、不降倍率** |

**结论：携行包满足「单调累积 + 单一明确消耗点 + 自动保护」三律，196 组合 × 5 流派在超时托管下永不死锁（`11 §11.8` 检查项 8 通过）。**

### 9.2 支援折算当量 G 的分解（可复核）

**单位约定**：`Δ当量 = 每次支援的效果（折算为全队 DPR 相对增幅 G_i）× 队伍当量`。

> 变动来自两处：① 团队受益项按 `$C.BALANCE.SUPPORT_CREDIT_TEAM`（0.55）折算（主控项按 `SUPPORT_CREDIT_SELF` 1.00 全额计入）；② 新增 S8/S9 两条主控向副效果作加法补偿。
> **这不改变玩家手上的任何已发放数值**——包型效果、M 倍率、充能速率全部原样，只是内部核算口径统一。

> **无双重计数校验**：① 的循环表（§9.1）中，随附支援**未贡献任何 M**（撒粉只改破坏槽、布陷只改压制量表、装弹只改异常积蓄、药剂只回 HP）——支援的全部价值都记在 ②。二者层位不重叠（行动层 vs 伤害公式），**不存在重复计算**。

### 9.6 与吟游诗人的"支援双雄"如何不串味（用户要求项）

## 附 B · 关键设计判断（五条）

1. **「不占主行动」是职业级规则，不是本命词条**。`02 §2.2.3` 把"不占回合"同时写进了核心动作 ② 与本命词条，二者重复。本卡判定：**归入职业级，跨武器恒定**。理由：① 生态位句"唯一支援不占回合者"是 `02 §2.4.4` 明列的**职业锚点三分之一**（资源的本质与结算层位不可被武器改写），若它只在剑盾下成立，则圣骑士 × 13 把非本命武器会集体丢掉身份锚，196 组合直接违反解耦原则；② 本命词条因此收敛为唯一一条「返还 +0.5 格」，既守住规格"唯一一条"，又让本命的强度落在**量**（支援永续）而非**机制开关**上，符合 `02 §2.2.15`（4）"本命词条是锦上添花而非机制开关"。

2. **携行包是"下限保障"，不是"上限枷锁"**。真正的节流阀有两个：**每回合最多取用 1 件**（本卡新增的硬上限，理由：异步环境下"一回合连开三件"会让战报不可读、且托管与在线差距拉大）与**战前条件 DSL 的触发判定**。格数只决定**开局 3 件的存货**与**短局（TTK 2–3）的支援次数上限**——这直接把"长局更强"写进资源曲线，与生态位句"长局与开荒的容错锚点"同向，也与 `$C.BALANCE.WINDOW_CONTRIB_MIN` 的长局要求一致。代价是长局中包长期接近满（见 §2.5：本命净流 +0.40 格/回合），本卡**不掩饰这一点**：携行包的设计目标是"支援永不断供"，稀缺感由触发条件提供。

3. **战术直注 +0.5 格走"每回合 1 次"，不随段数放大**。若按段计，双刃 4 段 = +2 格/回合，资源瞬间通胀，解耦彻底失衡（`02 §2.5.2` 边界②"段数只改副效果触发次数，不改触发规则"）。段数对本职业的正确落点是：撒粉的 ×2 **逐段生效**、装弹的 V 55 **按段分摊**——即段数放大的是**支援效果的作用次数**，不是格数注入。这也是双刃在矩阵里成为"高频异常铺底机"的原因。

4. **三包型等当量（W-05 后 0.0820 / 0.0825 / 0.0820，极差 **0.6%**）是刻意的**。三条支援线不比强弱，只比**对应哪一类贡献**（生存 / 破坏·压制 / 异常）。这么做同时满足三条红线：① 红线 8（战技变体选用率 ≥15%，实测各 0.30–0.36）；② 红线 4（职业层三包均权后配比 42/28/30，落在 40/30/30 ±10%）；③ 红线 5（每条包型自身都有 ≥40% 的主贡献：猎具 破坏 45%、炼金 异常 62%、急救 压制+生存 50%）。
   **W-05 分档折算一度把极差扩大到 50%**（纯团队向的猎具 / 炼金打 0.55 折，纯主控的急救不变）。处置是新增 **S8 破甲残留 / S9 余韵护持**——给两个纯团队向包型各补一条**主控向**副效果。这不只补回数值，更让每个包型都同时具备「团队价值 + 个人价值」，**结构比修正前更对称**（极差 2.2% → 0.6%）。**若未来需要收敛某条线的强度，按 `02 §2.4.4` 四级顺序应优先走第①级"加战技变体"，而非动倍率。**

5. **`02 §2.2.3` 的"每 2 回合 +1 格"被改写为条件性的「应急整备」（G4），仅在 `SL ≤ 1` 时启动**。理由：若作为常驻自然增长（+0.5 格/回合），叠加 G2 的 +0.5 后注入恒为 ≥1.0 格/回合，而消耗上限只有 1 格/回合 → **包在任何武器下都恒满，武器层的整备速度差异（0.18–0.32 格/回合）完全不可感，解耦在本职业上形同虚设**。改为条件性后：① 包在 1–3 格之间呼吸，资源真正"存在"；② 武器层的整备速度成为可感的差异（巨剑从容、轻弩贴地）；③ 它自动成为**保护律 ③**，与 `02 §2.5.3` 三律同源；④ 数值一字未改（仍是"每 2 回合 +1 格"），只改了**触发条件**。
