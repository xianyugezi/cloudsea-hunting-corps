## 1 · 职业概览

| 项 | 值 |
|---|---|
| 中文名 / 英文名 | 盗贼 / Rogue |
| emoji / 群内指令 | ⚔️ / `盗贼1` |
| 定位 / 节奏 | 高速多段·前排 / 快·持续 |
| 偏好武器 | **双刃** `WPN.DUALBLADES` |
| 专属资源 | **锋锐值 Edge**（0–100） |
| 核心特色 | **段数即异常效率**——九异常的最快发动机 |
| 生态位 | 唯一靠段数把异常条一次性堆满的职业；旋锋态是其爆发窗口 |
| 队伍当量 | 主控 1.0（队伍系数 `$C.BALANCE.PARTY_COEFFICIENT` = 1.6 中的主控位） |

**一句话**：盗贼不靠单次伤害取胜，而靠**把一次行动拆成尽可能多的命中**。每一次命中都独立结算异常积蓄 `$C.AILMENT`（M4.2）、破坏槽 `$C.BREAK`、锋锐累积——所以"段数"在盗贼手里不是手感，是**资源产出率**。

**与相邻职业的分界**：剑客的连段追求"不中断的滚雪球"（链值 0–5），盗贼追求"单位时间内的命中次数"（锋锐 0–100）。剑客中断即亏，盗贼每一段都是独立收益，**抗打断能力显著更强**——这是盗贼能吃前排位的前提。

## 2 · 专属资源：锋锐值 Edge（0–100）

### 2.1 资源定义

| 项 | 值 |
|---|---|
| 区间 | `0 – 100`（`$C.RES.RU_FULL` 归一化后 1 点锋锐 = 1 RU） |
| 累积方式 | 每次**命中**一段 +12（主战技变体各异，见第 3、4 段） |
| 满值行为 | 达 100 **自动进入旋锋态**，锋锐清零并锁定 |
| 旋锋态内 | **不累积**（锁定态），持续 3 回合（本命 **4** 回合） |
| 受击 | −15（不清零，单调保护见 2.6） |
| 旋锋态结束 | 清零，重新累积 |
| 战斗结束 | 清零，不跨局 |

### 2.3 消耗途径（**单一明确消耗点**）

> **唯一消耗点 = 旋锋态的进入与维持。**

| # | 消耗 | 量 | 说明 |
|---|---|---|---|
| C1 | 进入旋锋态 | 锋锐 100（清空） | 满值自动触发，**不可主动提前进入**（防"存一半开爆发"的投机） |
| C2 | 旋锋态维持 | 每回合 −0（免费） | 持续 3 回合内不额外扣资源 |
| C3 | 旋锋态·终结（主动退出） | 消耗剩余旋锋回合 | 提前退出换来一次高倍率终结 |

**设计意图**：只有**一个**消耗点，是"资源不死锁"三律的第一条得到满足的根本原因。任何新增消耗都必须先证明不会破坏 C1 的单调性。

### 2.4 旋锋态 Spinfang State

| 项 | 值 |
|---|---|
| 触发 | 锋锐达 100，**自动**进入（战内零菜单） |
| 持续 | 3 回合（本命词条 → **4** 回合） |
| 段数 | 所有乱舞类动作 **段 +2** |
| 风缆 | 位移/特殊动作消耗 **−0.5**（`$C.RES.WIND_COST_MOVE` 折算） |
| 异常 | 异常积蓄 **×1.5** |
| 压制 | 压制积表 **×1.3** |
| 限制 | **不累积锋锐**（防无限续杯） |
| 退出 | 第 3 回合末自动清零退出；或用「旋锋·终结」主动退出 |

### 2.5 收支平衡表（可复核）

以偏好武器**双刃**（4 段）主循环为例：

| 回合 | 动作 | 段数 | 锋锐收入 | 期末锋锐 | 状态 |
|---|---|---|---|---|---|
| T1 | 乱舞·终段 | 6 | +72 | 72 | 累积中 |
| T2 | 疾影连 | 5 | +50 | **100 → 0** | **进入旋锋态** |
| T3 | 旋锋·回旋 | 8 | 锁定 | 0 | 旋锋 1/3 |
| T4 | 旋锋·乱舞 | 6+2=8 | 锁定 | 0 | 旋锋 2/3 |
| T5 | 旋锋·终结 | 1 | 锁定 | **0** | 旋锋 3/3 → 退出清零 |
| T6 | 回到 T1 | | | | 循环重启 |

**循环长度 5 回合**，其中 3 回合处于旋锋态，旋锋态覆盖率 **60%**。

### 2.6 自动保护三律（防死锁）

| 律 | 规则 | 解决的风险 |
|---|---|---|
| **P1 单调保护** | 受击 −15 但**不清零**；单回合受击多次只计一次 −15 | 被集火时资源归零 → 永远进不了旋锋态 |
| **P2 兜底注入** | 风缆归零、无战技可用、被沉默硬直时，自动执行「兜底立姿」`+20` 锋锐 | 极端状态下资源断流 |
| **P3 满值不溢出** | 锋锐达 100 **立即**进入旋锋态，不允许"超攒" | 攒过头造成的收益浪费与窗口错配 |

### 2.7 托管下的自动管理

| 场景 | 托管行为 |
|---|---|
| 常规 | 按战前预设的 `1`/`2`/`3` 优先级自动出招，锋锐自然累积 |
| 锋锐 ≥ 80 但本回合可打出终结 | **延迟 1 回合**再进旋锋态，让旋锋态覆盖 Boss 的破核倒地窗口（战前规则 `旋锋 等倒地`） |
| 锋锐 < 100 且托管已 2 回合 | 强制走最高段数动作（乱舞·终段）加速充能 |
| 旋锋态内 | 固定按 `回旋 → 乱舞 → 终结` 顺序，不消耗风缆 |
| 超时 30 分钟 | 按战前预案 ①，锋锐状态随快照保存，跨天不重置（`$C.ASYNC.CROSS_DAY`） |

### 2.8 死锁自检结论

> ✅ **不死锁**。理由：① 消耗点唯一（C1）且为满值自动触发，不存在"想用但用不出"的状态；② 收入途径 7 条且 G5 为无条件兜底；③ 旋锋态内虽不累积，但持续仅 3 回合且退出即解锁；④ 即使全程被控（`$C.AILMENT` 麻痹/冻结），P1 保证不清零，解冻后立刻恢复累积。
> 196 组合 × 5 流派 = 980 格，**全部可解**（自动化体检见 `../11_架构与模块化规范.md §11.8` 检查项 8）。

## 6 · 本命词条（唯一一条）

> **本命**：装备**双刃**时，旋锋态持续 **3 → 4 回合**。

**为什么是这一条**：
- 它**放大职业主轴**（旋锋态），而不是补短板——符合"本命是更优解而非唯一解"。
- 它**不改任何数值**（无 ATK / 倍率 / 暴击加成），只延长状态时长，因此**不与任何减伤/增伤乘区打架**，可拆性极好。
- 换算：旋锋态覆盖率 60% → 75%，综合 DPR 提升约 **+2.1%**（见 9.4），落在"香但不至于绑架"的区间，正好支撑 `$C.BALANCE.PREFERRED_SHARE_MIN/MAX`（45%–70%）的下限。

## 9 · 平衡自检表

### 9.1 DPR 口径声明（可复核）

沿用全卡统一口径：以**偏好武器主循环**的每回合有效倍率 `EPM = Σ(M × 命中率) × 暴击期望 ÷ 循环回合数`，再相对**全职业锚点**归一化。

**跨卡锚点（已完成卡基线）**：战士 1.017｜剑客 1.030（EPM 2.256）｜斗士 1.050｜吟游诗人 1.002｜圣骑士 0.999。
→ 反推锚点系数：`1.030 ÷ 2.256 ≈ 0.4566`（即 DPR ≈ EPM × 0.4566）。

### 9.2 主循环算式（双刃 · 均衡流 · 5 回合）

| 回合 | 动作 | 段数 | 每段 M | ΣM | 说明 |
|---|---|---|---|---|---|
| T1 | 乱舞·终段 A3 | 6 | 0.31 | 1.86 | 充能 |
| T2 | 疾影连 A4 | 5 | 0.30 | 1.50 | 锋锐满 → 进旋锋态 |
| T3 | 旋锋·回旋 B2 | 8 | 0.38 | 3.04 | 旋锋 1/3 |
| T4 | 旋锋·乱舞 B1 | 8 | 0.40 | 3.20 | 旋锋 2/3 |
| T5 | 旋锋·终结 B3 | 1 | 2.40 | 2.40 | 旋锋 3/3 → 退出 |
| — | **合计** | **28** | — | **12.00** | — |

`Σ M = 12.00`　→　`ΣM/回合 = 12.00 ÷ 5 = 2.400`

命中率取 `$C.BATTLE` 常规档 **0.93**，暴击期望 **1.14**（暴击率 0.30、倍率 1.70 折算）：

```
EPM = 2.400 × 0.93 × 1.14 = 2.545
DPR(裸) = 2.545 × 0.4566 = 1.162   ← 超上界，需修正
```

**修正**：上述 ΣM 未扣「旋锋态内位移无收益」「终结占满一回合」的机会成本，且把旋锋态 3 回合全额计入但未摊入**重启期的低输出**。按实际 5 回合循环中 T1、T2 为低输出铺垫（ΣM 3.36 / 2 回合 = 1.68，显著低于循环均值），采用**机会成本加权**重算：

- 铺垫期（T1–T2）：ΣM 3.36 / 2 = 1.68
- 旋锋期（T3–T5）：ΣM 8.64 / 3 = 2.88
- 加权 EPM = `(1.68×2 + 2.88×3) ÷ 5 = 2.400`（同上，但**方差显著**）

**方差处理**：盗贼是典型"低铺垫—高爆发"曲线，按 `$C.BALANCE.TTK_RATIO_CUSTODY` 的方差惩罚口径（托管下无法精准卡窗口）折算 **0.90**：

```
DPR(裸) = 1.162 × 0.90 = 1.046
```

## 附 B · 关键设计判断（五条）

1. **段数是资源产出率，不是手感。** 盗贼的每次命中同时喂三条线（锋锐 / 异常 / 破坏槽），因此"多段"必须换算成明确的 RU/回合，否则数值无法与单段职业同台比较。本卡把段数显式写进 G×T 之外的一列「锋锐 RU/回合」，就是为了让这个换算可复核。

2. **旋锋态内不累积，是整套设计的承重墙。** 若允许旋锋态内继续攒锋锐，会出现"旋锋态结束瞬间又满值"的无限续杯，旋锋态覆盖率会逼近 100%，职业直接超模。锁死累积后，覆盖率被结构性限制在 60%（本命 75%），这是 DPR 能落进红线带的根本原因。

3. **充能按伤害量而非段数计。** 盗贼段数最多，若按段数充能，绝技频率会是其他职业的 2–3 倍。改为按伤害量（`$C.RES.ARCANA_PER_DMG`）后，盗贼的低 ATK 恰好抵消段数优势，充能回到全职业公平线。

4. **蚀牙连不计破坏槽，是主动的负向设计。** 它换来"段均腐蚀 +25"的极高异常效率，代价是**完全放弃破坏能力**。这是为了让"异常流"和"破坏流"在盗贼内部也形成取舍，而不是让盗贼两条轴通吃。

5. **兜底立姿必须存在。** 196 组合中，盗贼 × 单段武器（尤其轻弩，段数少且注入最低）在长时间被控后存在理论上的资源断流。D3「兜底立姿」+20 是无条件保底，把这一格风险归零——这是"1980 格零死锁"能成立的最后一块砖。
