## 1 · 职业概览

| 项 | 值 |
|---|---|
| 中文名 / 英文名 | 狂战士 / Berserker |
| emoji / 群内指令 | 🪓 / `狂战士1` |
| 定位 / 节奏 | 双形态·前排 / 中·爆发 |
| 偏好武器 | **战斧** `WPN.WARAXE`（单/双段形态 · 近战 1 · G×T 30） |
| 专属资源 | **形态值 Fury**（0–100） |
| 核心特色 | **可自排输出曲线**——把爆发送进倒地窗口 |
| 生态位 | 唯一能主动决定"这一轮爆发什么时候来"的职业；斧是充能态，剑是消耗态 |
| 队伍当量 | 主控 1.0（队伍系数 `$C.BALANCE.PARTY_COEFFICIENT` = 1.6 中的主控位） |

**一句话**：其他职业的爆发是"资源攒满了就放"，狂战士的爆发是"**资源攒满了，但什么时候放由我决定**"。形态值满 100 只是取得了**入剑资格**，真正的决策是"现在进，还是再等两回合等到 Boss 倒地再进"。

**与相邻职业的分界**：
- vs 战士（同为蓄力爆发）：战士的蓄力阶是**回合数换倍率**（3 回合后必定释放，早放亏、晚放卡手），狂战士的形态值是**充能池**（满了可以一直存着，等窗口）。战士是被动节奏，狂战士是主动排程。
- vs 守卫（同为资源变现）：守卫的充能核靠**挨打**攒（被动），狂战士的形态值靠**打人**攒（主动）。
- vs 盗贼（同为状态爆发）：盗贼的旋锋态是**满值自动触发**（不可控时机），狂战士的剑形态是**满值后手动入剑**（可控时机）。这是"自排曲线"与"自动循环"的本质区别。

## 2 · 专属资源：形态值 Fury（0–100）

### 2.1 资源定义

| 项 | 值 |
|---|---|
| 区间 | `0 – 100`（`$C.RES.RU_FULL` 归一化后 1 点形态值 = 1 RU） |
| 累积（斧形态） | 命中 **+18/回合**（重斧式战技 **+25**） |
| 消耗（剑形态） | 每回合 **−12**；受击额外 **−6** |
| 入剑门槛 | 形态值 ≥ 100 方可入剑（战前可设更低门槛，见 2.4） |
| 强制回斧 | 形态值 **< 20** 时强制回到斧形态 |
| 切换成本 | **不占行动**（核心机制） |
| 战斗结束 | 清零，不跨局 |

### 2.2 获取途径（逐条）

| # | 途径 | 增量 | 依赖敌人行为 |
|---|---|---|---|
| G1 | 斧形态命中 | **+18/回合** | ❌ 否 |
| G2 | 重斧式战技命中 | **+25/回合** | ❌ 否 |
| G3 | 部件破坏 | +15 | ❌ 否 |
| G4 | 瞬御成功 | +12 | ❌ 否 |
| G5 | 绝技「狂澜形态」 | +30 | ❌ 否 |

> **全部来源不依赖敌人行为**——与骑士（G1 突刺命中）同理，狂战士的抗死锁基础扎实。

### 2.3 消耗途径（**单一明确消耗点**）

> **唯一消耗点 = 剑形态的每回合维持（−12）。**

| # | 消耗 | 量 | 说明 |
|---|---|---|---|
| C1 | 剑形态维持 | **−12/回合** | 唯一的持续消耗 |
| C2 | 剑形态受击 | **−6/次** | 承伤即掉形态，是剑形态的隐性风险 |
| C3 | 入剑 / 回斧 | **0** | 切换**不占行动、不耗资源**——这是本职业的机制核心 |

**为什么切换免费**：若切换占行动或耗资源，"自排输出曲线"就变成了"付费换形态"，玩家会倾向于**少切**，职业退化成单形态。免费切换保证了"频繁切换"是可行策略，这才是生态位成立的代价。

### 2.4 入剑门槛（可配置 · 生态位核心）

| 门槛 | 战前指令 | 效果 | 适用 |
|---|---|---|---|
| **满值入剑** | `形态 100 入剑` | 形态满 100 才入剑，剑形态可维持约 6 回合 | 长线稳定，DPR 最优 |
| **储备入剑** | `形态 70 入剑` | 70 即可入剑，剑形态约 4 回合 | 快节奏，牺牲续航换频率 |
| **窗口入剑** | `形态 ≥60 且 敌倒地 入剑` | 倒地窗口一到就入剑 | **本职业的灵魂用法**——把爆发送进 ×1.5–1.8 倒地窗口 |
| **血线入剑** | `形态 ≥50 且 血线<40% 入剑` | 残血时爆发翻盘 | 高风险构筑 |

> **战前规则示例**（DSL 形式）：
> ```yaml
> - id: berserker_window_entry
>   when: { op: "AND", args: [
>     { op: ">=", left: "$resource.fury", right: 60 },
>     { op: "==", left: "$target.state", right: "DOWNED" } ] }
>   then: { action: "enter_sword_form" }
> ```

### 2.5 收支平衡表（可复核）

以偏好武器**战斧**、满值入剑（100）为例：

| 阶段 | 回合 | 动作 | 形态收支 | 期末形态 | ΣM |

| 斧 | T1–T6 | 斧形态 M 1.6 | +18 × 6 = +108 | **100**（封顶） | 9.6 |
| — | T6末 | **入剑**（不占行动） | 0 | 100 | — |
| 剑 | T7 | 剑形态 2 段 × M 1.30 | −12 | 88 | 2.60 |
| 剑 | T8 | 剑形态 | −12 | 76 | 2.60 |
| 剑 | T9 | 剑形态 | −12 | 64 | 2.60 |
| 剑 | T10 | 剑形态 | −12 | 52 | 2.60 |
| 剑 | T11 | 剑形态 | −12 | 40 | 2.60 |
| 剑 | T12 | 剑形态 | −12 | 28 | 2.60 |
| — | T13 | 形态 28 ≥ 20，可继续；若继续则 T13 末形态 16 < 20 强制回斧 | | | |

### 2.6 自动保护三律（防死锁）

| 律 | 规则 | 解决的风险 |
|---|---|---|
| **P1 形态归零不惩罚** | 形态值归零**只是强制回斧**，回斧后立刻可以重新充能；**无任何额外惩罚**（不晕、不降防、不空过） | ★ 本职业最大风险：形态耗尽被视为"资源枯竭"，玩家感到被惩罚 |
| **P2 充能完全自主** | 形态值的 5 条来源全部不依赖敌人行为 | 被控/敌人不打你时依然能攒 |
| **P3 受击不清零** | 剑形态受击 −6 但**不清零**；单回合多次受击至多 −6 | 被集火时形态瞬间蒸发 |

### 2.7 托管下的自动管理

| 场景 | 托管行为 |
|---|---|
| 常规 | 按战前设定的入剑门槛规则自动切换（**这是托管与在线差距最小的职业之一**，因为切换规则可完全数据化） |
| 形态 ≥ 门槛 且 Boss 正常 | 立即入剑（不等窗口） |
| 形态 ≥ 门槛 且 已设「窗口入剑」 | 等待倒地窗口；若连续 3 回合无窗口则强制入剑（防无限等待） |
| 剑形态 且 形态 < 30 | 主动回斧（不等强制），避免强制回斧的突发断档 |
| 血线 < 40% | 若已设「血线入剑」，残血时自动入剑爆发 |
| 超时 30 分钟 | 按战前预案 ①，形态值与当前形态随快照保存，跨天不重置（`$C.ASYNC.CROSS_DAY`） |

### 2.8 死锁自检结论

> ✅ **不死锁**。理由：① 形态值的唯一消耗是"剑形态维持"，而维持本身是可随时终止的（回斧免费）；② P1 保证归零无惩罚，回斧即恢复充能；③ 全部来源自主。
> 最坏情况（形态归零 + 全程被控）：解冻后 6 回合即可重新满值。
> 196 组合 × 5 流派 = 980 格，**全部可解**。

> ⚠️ **但有一个非死锁的体验风险**：满值入剑的 12 回合循环意味着 Boss 战（TTK 15–20 回合）中**只能跑完 1.5 个循环**。若玩家错过了唯一的倒地窗口，会有一整轮没有爆发。这是**设计意图**（自排曲线的代价），但必须在 UI 上给足提示——战报中须显示形态条与该职业的"爆发就绪"标记。

## 6 · 本命词条（唯一一条）

> **本命**：装备**战斧**时，形态值满 100 入剑当回合**追加 M 2.0 切换斩**。

**为什么是这一条**：
- 它强化的是**入剑这一瞬间**——正是"自排输出曲线"这个生态位的核心动作。玩家把入剑时机卡在倒地窗口时，本命词条让这次爆发的收益再上一层。
- 它是**追加动作**而非乘区，因此不与 D（流派）、Xa（异常易伤）、压制倒地乘子冲突，可拆性极好。
- 换算：每次入剑额外获得 2.0 倍率，按 12 回合循环折算约 **+0.019** DPR（见 9.3），属于"香但不绑架"的区间。

**与迸斧式的关系**：战技「迸斧式」提供的是**同类的更高值**（M 2.40 + 压制 +50）。二者**取高不叠加**——这是刻意的，避免"本命 + 战技"形成必选组合。不带迸斧式时，本命给了保底的 M 2.0；带了则升级但占用主战技位（失去重斧式的快速蓄能）。

**推荐组合**：**狂战士 × 战斧 × 强袭流** + 战前规则 `形态 ≥60 且 敌倒地 入剑` + 主战技**迸斧式**——把 M 2.80 的切换斩、本命的追加斩、倒地窗口 ×1.5–1.8 三重叠加，是全游戏**单回合爆发上限最高**的构筑之一。

## 9 · 平衡自检表

### 9.1 DPR 口径声明（可复核）

`EPM = Σ(M × 命中率) × 暴击期望 ÷ 循环回合数`，再相对全职业锚点归一化。
**锚点系数**：`1.030 ÷ 2.256 ≈ 0.4566`（源自剑客 EPM 2.256 / DPR 1.030）。

### 9.2 主循环算式（战斧 · 均衡流 · 满值入剑 · 12 回合）

| 阶段 | 回合数 | 动作 | 每回合 M | 小计 ΣM |
|---|---|---|---|---|
| 斧形态 | 6 | 斧击 A1 | 1.60 | 9.60 |
| 剑形态 | 6 | 剑连击 B1（2 段 × 1.30） | 2.60 | 15.60 |
| **合计** | **12** | | | **25.20** |

```
ΣM/回合 = 25.20 ÷ 12 = 2.10
```

命中率 **0.93**，暴击期望 **1.14**：

```
EPM = 2.10 × 0.93 × 1.14 = 2.227
DPR(裸) = 2.227 × 0.4566 = 1.017
```

### 9.3 协同修正

| 项 | 修正量 | 依据 |
|---|---|---|
| 裸循环 DPR | 1.017 | 9.2 |
| 本命切换斩（每次入剑 +2.0，按 12 回合摊入） | **+0.019** | 2.0 ÷ 12 回合 ÷ 2.227 × 0.4566 ≈ 0.019 |
| 破坏贡献（剑形态 ×1.6；崩山斧 45 槽） | **+0.020** | — |
| 异常贡献（剑形态双段，效率仅次于盗贼） | **+0.012** | — |
| 压制贡献（切换当回合 +35；迸斧式 +50） | **+0.018** | — |
| 绝技贡献 | **+0.034** | 终焉剑舞 ΣM 4.80，按充能周期摊入 |
| **自排曲线结构价值**（把爆发送进倒地窗口） | **+0.022** | 倒地窗口 ×1.5–1.8，按命中窗口率 60% 折算 |
| 形态管理的托管损耗（托管无法精准卡窗口） | **−0.048** | TTK 比 1.26 折算 |

```
DPR(综合) = 1.017 + 0.019 + 0.020 + 0.012 + 0.018 + 0.034 + 0.022 − 0.048 = 1.094
```

> ⚠️ **1.094 超出 1.08 上界**，需修正（见 9.4）。

### 9.4 DPR 修正：把"窗口入剑"作为**基准口径**而非额外加分

**问题诊断**：上面的算式犯了**双重计数**——"自排曲线结构价值 +0.022"与"托管损耗 −0.048"两项，前者假设玩家能精准卡窗口，后者假设托管不能，两者混在同一个数字里。

**修正**：改用**两个独立口径**分别给出，取加权：

| 口径 | 说明 | 计算 | 结果 |
|---|---|---|---|
| **在线 · 窗口入剑** | 玩家精准卡倒地窗口 | 裸 1.017 + 本命 0.019 + 破坏 0.020 + 异常 0.012 + 压制 0.018 + 绝技 0.034 + **窗口 0.022** | **1.142** |
| **托管 · 门槛入剑** | 到门槛即入剑，不卡窗口 | 裸 1.017 + 本命 0.019 + 破坏 0.020 + 异常 0.012 + 压制 0.018 + 绝技 0.034 | **1.120** |

> 两个口径**都超 1.08**。说明裸循环本身偏高，需下调基础倍率。

**基础倍率修正**：将剑形态每段 M 由 **1.30 → 1.22**（ΣM 2.44/回合），斧形态 M 保持 1.60：

```
ΣM = 1.60×6 + 2.44×6 = 9.60 + 14.64 = 24.24
ΣM/回合 = 24.24 ÷ 12 = 2.020
EPM = 2.020 × 0.93 × 1.14 = 2.142
DPR(裸) = 2.142 × 0.4566 = 0.978
```

| 口径 | 重算 | 结果 | 判定 |
|---|---|---|---|
| 在线 · 窗口入剑 | 0.978 + 0.125 | **1.103** | ⚠️ 仍略超 |
| 托管 · 门槛入剑 | 0.978 + 0.103 | **1.081** | ✅ 勉强合规 |

**再次修正**：剑形态每段 M **1.30 → 1.15**（ΣM 2.30/回合）：

```
ΣM = 9.60 + 2.30×6 = 9.60 + 13.80 = 23.40
ΣM/回合 = 23.40 ÷ 12 = 1.950
EPM = 1.950 × 0.93 × 1.14 = 2.068
DPR(裸) = 2.068 × 0.4566 = 0.944
```

| 口径 | 重算 | 结果 | 判定 |
|---|---|---|---|
| **在线 · 窗口入剑** | 0.944 + 0.125 | **1.069** | ✅ |
| **托管 · 门槛入剑** | 0.944 + 0.103 | **1.047** | ✅ |
| **职业层加权**（在线 40% / 托管 60%） | | **1.056** | ✅ |

> **最终采用**：剑形态 **2 段 × M 1.15**（ΣM 2.30/回合）。
> **与设计稿的差异说明**：设计稿原值为"剑形态 2 段 × M 1.3"。按全卡统一 DPR 锚点复算后，M 1.3 会使综合 DPR 达 1.094–1.142，**超出 0.92–1.08 红线带**。因此下调至 1.15，并在「疾剑式」（1.05）「崩剑连」（1.25）两个变体上保留向上空间——**M 1.3 由崩剑连（1.25）近似承接**，原设计意图未丢失。已在附 A 登记为待裁决项。

## 附 B · 关键设计判断（五条）

1. **形态切换必须免费，这是承重墙。** 一旦切换占行动或耗资源，玩家就会倾向于"少切"，狂战士退化成单形态职业，"自排输出曲线"的生态位立刻崩塌。这一条写进了常量表建议（`$C.CLASS.BERSERKER.SWITCH_ACTION_COST = 0`），是**不可协商**的设计约束——任何"为了平衡而让切换付费"的改动都是拆东墙补西墙。

2. **本卡的 DPR 校准经历了两次修正，值得记录。** 初版直接采用设计稿的"剑形态 2 段 × M 1.30"，复算后综合 DPR 达 1.094（在线口径 1.142），**超出红线**。第一次修正到 M 1.22 仍略超（1.103），第二次到 M 1.15 才落进带内。**教训**：设计稿中的单点倍率是在"未做全职业归一化"时给出的，进入数值卡阶段必须按统一锚点复核，不能照抄。已在附 A 把 1.30 登记为待裁决项，若主策划认为狂战士应有更高上限，可通过上调 `$C.BALANCE.DPR_ANCHOR_COEF` 全职业统一解决，而不是单独放宽这一个职业。

3. **"自排曲线"的价值与代价必须分开计。** 初版算式把"窗口卡位收益 +0.022"与"托管损耗 −0.048"混在一起，得出 1.094 这个既不在线也不托管的中间值。修正后改为**两个独立口径**（在线 1.069 / 托管 1.047），物理意义才清晰：这个职业在线比托管强约 2%，差距来自窗口卡位，而不是数值本身。

4. **12 回合长循环是特性不是 bug，但必须有 UI 兜底。** 满值入剑的循环长度意味着巨兽战（TTK 15–20 回合）只能跑 1.5 轮。这是"重爆发"职业应有的代价，但战报中**必须**显示形态条与"爆发就绪"标记，否则玩家会感觉"打了半天没爆发"。建议 UI 在形态 ≥80 时给出 `🪓⚡ 形态就绪` 提示。

5. **远程带武器的充能补偿是必要的。** 战斧是近战武器，狂战士天生绑定前排。若不给远程带武器额外充能，轻弩组合的 WKR 只有 0.60，等于"远程选项形同虚设"。补偿后 WKR 达 0.92——**略高于近战带**，这是刻意的：远程带失去了剑形态的机动优势（风缆 +1），用充能速率找补。
