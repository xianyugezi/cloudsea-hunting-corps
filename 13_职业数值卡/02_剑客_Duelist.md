## 1 · 职业概览

| 项 | 值 |
|---|---|
| 中文名 / 英文名 | 剑客 / Duelist |
| emoji / 群内指令 | ⚡ / `剑客2` |
| 定位 / 节奏 | 连段位移·前排 / 中·持续 |

| 核心特色（一句话） | **连段越长收益越高**：链值把一次普通挥击滚成五段连斩，再一次性兑现成终结回旋。 |
| 生态位（一句话） | **唯一边打边挪、越连越强**者——追末端件、抢位移压制窗口，无替代。 |

**一句话玩法**：战前配好「主战技（终结方式）+ 副战技（位移方式）+ 保底位（兜底）+ 释放阈值」，战内只发 `1`，链值自动累积、自动展开追加段、到阈值自动回旋；玩家唯一的战内判断是"这一拍要不要走 `2`/`3`"。

## 2 · 专属资源：链值 Chain（0–5）

### 2.1 定义与换算

| 项 | 值 |
|---|---|
| 名称 | 链值 Chain（群内显示 `⚡链 3/5`） |
| 区间 | `0 – 5`（职业专属） |
| RU 换算 | **1 链 = `$C.RES.RU_FULL ÷ 5` = 20 RU**；满链 5 = `$C.RES.RU_FULL` = 100 RU |
| 余量处理 | 不满 20 RU 的余额进「**余链池**」（0–19 RU），跨回合保留，不跨局 |
| 结算层位 | **M 层 · 八步第 ① 步**（见 `02` §2.5.1：链值走 M、吃 H、与 X 无关、累积破坏槽） |

### 2.2 获取途径（逐条）

| # | 途径 | 数量 | 说明 |
|---|---|---|---|
| G1 | **连段命中**（主途径） | `链 + floor( (本回合注入 RU + 余链池) ÷ 20 )`，**保底 +1** | 注入 RU = `武器 G×T × 档位系数 × (1 + 0.20 × 追加段数)`；档位系数见 §2.2.15（本命 `1.25`，其余 `1.00`） |
| G2 | **位移命中**（踏风斩 / 曳光撤步 / 绝技「逐风连影」） | 链 **+2**；**本命长刀下 +3** | 设计稿明文；本命词条见第 6 段 |
| G3 | **暴击命中** | 链 +1（每回合最多 1 次） | 职业专属：把"打得好"直接接进滚雪球 |
| G4 | **部件破坏** | 链 +1 | 与 `$C.RES.ARCANA_ON_BREAK`（绝技充能）并行，互不冲突 |
| G5 | **瞬御成功追击命中** | 链 +1（追击倍率用 `$C.RIPOSTE.COUNTER_MULT`） | 软依赖 `S02 意图瞬御` |
| G6 | **空振保底（自动保护律）** | 链 +1 | 仅当"本回合所有攻击段全部未命中"时触发；用于对抗 🌪️ 风蚀（命中 −25%）、🟤 泥陷与远程高闪避 |

### 2.3 消耗途径（单一消耗点）

> **全职业只有 1 个需要判断的消耗点**：主战技位的终结技释放。战前给阈值，到点自动执行——这是托管 AI 与在线玩家共用同一套条件求值器的前提（`11` §11.4 N4）。

| 主战技变体 | 消耗 | 释放后链值 |
|---|---|---|
| 回旋·终 | 清空全部链值 | 0 |
| 连锁·续锋 | 清空后回填 | 2 |
| 断链斩 | 固定消耗 3 链 | `链 − 3` |

其余（连段、位移、防御、换位、道具、剥取）**均不消耗链值**。

### 2.4 自然增长 / 衰减

| 项 | 规则 |
|---|---|
| 自然增长 | **无**。链值只由 §2.2 的六条途径注入——保证"链 = 打出来的"，不是白给的 |
| 自然衰减 | **连续 3 个回合无任何链值注入 → 链 −1**，计数器在任意一次注入后清零（设计稿："3 回合无命中 −1"） |
| 衰减下限 | 衰减**不使链值低于 0**；且**链 = 0 时不再触发衰减**（0 已是地板） |
| 受击变化 | **被击中 → 链值减半、向下取整**（`floor(链 ÷ 2)`），**不清零、不倒扣**；一次多段攻击只结算 1 次减半 |
| 清零规则 | ① 回旋·终释放后归 0；② 战斗/阶段结束清空（不继承到下一局）；③ 阶段转换**保留全部链值**（与 `$C.AILMENT.PHASE_INHERIT` 无关，链值不参与异常遗产） |

### 2.5 自动保护三律 + 死锁自检

| 律 | 内容 | 作用 |
|---|---|---|
| **① 单调律** | 链值只由正向事件增长；受击仅"减半取整"，永不出现清零 / 负数 / 倒扣 | 代打不可能把资源打到无效态 |
| **② 空振保底律** | 整回合零命中仍 +1 链（G6），且**不依赖命中判定** | 被风蚀 / 泥陷 / 高闪避压制时，托管仍能滚链，不会出现"打不中 → 攒不动 → 更打不中" |
| **③ 续链律**（托管专用） | 托管 AI 判定：`链 ≤1 且风缆 ≥$C.RES.WIND_COST_MOVE 且副战技位开放 → 自动执行踏风斩（链 +2/+3）`；`副位被锁或风缆 = 0 → 执行连段（保底 +1 链）` | 跨域组合（副位锁通用池）与归零风缆下仍有兜底，永不空过 |

**最低可行态验算**：链 = 0 时，连段恒定可用（长刀 2 段 ΣM = 1.26，含命中期望 1.06），回旋 M = `0.9 + 0.5×0` = **0.90 ≥ `$C.BATTLE.MULT_M_MIN`**。即**链值低只降低收益，从不剥夺行动权**——这是链值类资源不死锁的结构性保证。

> **死锁自检结论（§11.8 检查项 8）**：链值满足「单调累积 + 单一消耗点 + 自动保护」三律，且最低态（链 0）输出合法。对 **196 组合 × 5 流派 = 980 格**逐格验算：注入速率最慢格（轻弩，`G×T` 18）在空振保护下仍能于 6 次行动内满链；最快格（巨剑，`G×T` 32）4 次行动满链。**全部 980 格在 `$C.BATTLE.TTK_HARD_CAP`（40 回合）内可完成任意次完整循环，无"资源耗尽且无恢复手段"状态 → 死锁率 0。**

### 2.6 连段展开规则（链值如何变成"更长的连段"）

```
追加段数 A = min( ceil(链值 × 武器段数 ÷ 4) , 5 − 武器段数 )
实际段数 S = min( 5 , 武器段数 + A )
连段 ΣM   = Σ L[n]  (n = 1 … S)
```

| 参数 | 值 | 归属 |
|---|---|---|
| 段倍率表 `L[n]` | `0.60 / 0.66 / 0.72 / 0.78 / 0.84` | 本职业专属（全部 ≥ `$C.BATTLE.MULT_M_MIN`） |
| 追加段注入系数 | `0.20`（每个追加段使本回合注入 RU +20%） | 本职业专属 |
| 段数封顶 | `5` | 本职业专属 |
| 追加段破坏贡献 | 基础值的 `0.5 ×` | 本职业专属（防段数叠加把破坏槽打穿） |

**含义**：链值每满 `4 ÷ 武器段数` 点，连段多一段。长刀（2 段）每 2 链 +1 段；长枪（3 段）每 1.34 链 +1 段；双刃（4 段）每 1 链 +1 段；单段武器每 4 链 +1 段（最多 3 段）。**多段武器滚雪球更快、单段武器更慢——这是"连段"这一职业语言与武器的自然耦合，不是数值惩罚。**

**段位命中递减（风险侧）**：第 n 段命中率 `h[n] = $C.BATTLE.BASE_ACC_MELEE × decay[n]`，`decay = 1.00 / 0.97 / 0.93 / 0.88 / 0.84`（职业专属）。任一段 Miss → **该段之后的所有段作废（断链）**，已结算段照常出伤；断链回合仍走 G1 保底 +1 链。

| T3 | 3 | 4 | 2.76 | **1.95** | `30 × 1.4 = 42`（+余 6 = 48）→ +2 链 | 8 |
| T4 | 5 | — | 3.40 | **3.23** | 清空链值 | 8（结转下轮） |

**逐项代入**：

```
Σ(M × 命中)        = 1.06 + 1.54 + 1.95 + 3.23             = 7.78
暴击期望 C_e       = 1 + 暴击率 × (暴击倍率 − 1)
                   = 1 + 0.20 × (1.80 − 1)                 = 1.16
                     （暴击率取 $C.BATTLE.CRIT_SOFT_CAP 以下的常规值 0.20；
                       暴击倍率取 $C.BATTLE.CRIT_MULT_MIN/MAX 中值 1.85，保守取 1.80）
每回合有效倍率 G_e = 7.78 ÷ 4 × 1.16                        = 2.256
归一化 DPR         = 1,000 × G_e ÷ 1,000                    = 2.256
```

**跨职业锚（全职业均值 = 1.00）反推**：

```
取 `01` M1.5「上位·异相种 EHP 16,000 / TTK 8–12（取 10）」→ 队伍 DPR = 1,600
主控 DPR = 1,600 ÷ $C.BALANCE.PARTY_COEFFICIENT (1.6)      = 1,000 / 回合
中期主控 ATK 取设计基准 1,000（$C.BATTLE.ATK_MIN/MAX = 300/2200 内）
DEF 取 700 → K = $C.BATTLE.DEF_CONST / (400 + 700)         = 0.364
异常乘区 X 均值 1.15；流派 D 均值 1.10
→ 全职业平均「每回合裸有效倍率」G_ref = 1,000 ÷ 1,000 ÷ (0.364 × 1.15 × 1.10)
                                                            = 2.17
```

**结论（裸循环）**：`DPR_剑客 = G_e ÷ G_ref = 2.256 ÷ 2.17 = **1.04**`

**协同修正**：

| 项 | 修正 | 依据 |
|---|---|---|
| 破坏：回旋 ×1.3 且可指定末端件 | **+3%** | 末端件 H 更软且破坏槽更浅；`$C.BREAK.BREAK_DOWN_COUNT` 达成更快 |
| 异常：💫麻痹（追加段 V 46/52/58 + 回旋 V 70） | **+2%** | 麻痹窗口让回旋免吃反击；阈值 `$C.AILMENT` 九态表 |
| 压制：位移后 +25，御风流再 ×`$C.RES.WIND_AIR_OVERRIDE_MULT` | **+2%** | 倒地窗口 `$C.BREAK.DOWN_WINDOW_TURNS` 内可塞一次回旋 |
| 站位风险：前排贴脸，承伤高于远程 | **−4%** | 受击 → 链值减半，等效输出损失 |
| 无范围能力（全表单体） | **−2%** | 多部位/召唤场景的机会成本 |

**综合 DPR = 1.04 × (1 + 0.03 + 0.02 + 0.02 − 0.04 − 0.02) = 1.04 × 1.01 = 1.05 → 保守取 1.03**

> **红线对照：`$C.BALANCE.DPR_BAND_MIN / MAX = 0.92 / 1.08` → 本卡 1.03 ✔ 落在带内（距中位 1.00 偏 +3%）。**

3. **机制保留**：链值的阈值、单一消耗点、三律一条不变；四个绝技条目从配置单自动隐藏；绝技特有的"位移喂链"（逐风连影）改由副战技位踏风斩承担（跨域副位被锁的组合除外，此时由 G6 空振保底 + G1 保底 +1 链兜底，仍不死锁）。

### 10.2 若 `S12 同行兽` 被拆除

2. **绝技「逐风连影」**：同行兽支援子项静默跳过（R4 空安全），位移 + `链 +3` 主效果不变。

- **号角 0.57 / 法杖 0.60 低于 WKR 0.82**：两把为全表 ATK 最低（340 / 360）的纯功能武器，任何纯输出职业持有都会同幅下滑。处置同样走加法：为这两把武器在剑客名下补一条"功能转输出"的保底位变体（如"演奏/施法回合累积链值"），或在巨兽抗性表中投放"低 ATK 高功能"友好机制。

### D · 本卡的关键设计判断（三条）

1. **把"连段越长收益越高"落到段数上，而不是倍率上**。链值同时驱动三件事——追加段数（伤害）、每段独立触发副效果（异常/破坏）、追加段注入加速（滚雪球）——这样"滚雪球"是可感知的**结构性**变化，而非一个乘区数字。
2. **链值必须是"只降收益、不夺行动权"的资源**。链 0 时连段 1.26、回旋 0.90 均合法，这是"链值类资源永不死锁"的结构性保证；再叠加"空振保底"与"续链律"，使 196 组合在风蚀/泥陷/高闪避/跨域无位移的极端情况下仍能滚链。
3. **本命只放大"位移喂链"这一条轴**。不放大裸连段，是为了让"剑客 × 重弩/晶铳"这类站桩远程组合有独立的、非劣化的价值（零反击 + 高单发），从而把 HPR 压在 45–70% 的合理区间，而不是把本命做成唯一解。
