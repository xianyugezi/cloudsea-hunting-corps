## 附：常见裁定类型参考

| 类型 | 记录重点 |
|---|---|
| **口径不一致**（多张卡算法不同） | 统一后的口径 + 各卡重算结果 + 为何不采用其他口径 |
| **数值越界**（DPR 超上下限） | 越界幅度 + 归因（设计问题 or 记账问题）+ 合规路径 |
| **豁免**（明知不一致但暂不改） | ★ 豁免理由 + **收回豁免的明确条件** |
| **延后**（依赖跨模块联合改动） | 阻塞项 + 触发时机 |
| **否决**（明确不做） | 否决理由 + 重评估条件（防止反复讨论） |
